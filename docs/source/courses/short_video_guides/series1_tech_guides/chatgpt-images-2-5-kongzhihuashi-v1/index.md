# Images 2.5：可控创作

可控图像创作的重点不只是一次生成，而是把参考图、草图、局部编辑、多轮修订与人工验收组织为工作流。无论模型能力如何，文字准确、主体一致和局部修改不影响全图，仍需要用具体结果验证。

```{figure} images/scene01_img01_workbench.png
:alt: 参考图、提示词、编辑和复核组成的可控创作工作台
:width: 100%

把生成看成可迭代工作流，而不是一次性抽奖。
```

```{figure} images/scene02_img01_dalle2.png
:alt: 早期图像生成以一次性结果为主
:width: 100%

一次性生成能快速探索方向，但返工时难以精确保留未修改部分。
```

```{figure} images/scene02_img02_gpt4o.png
:alt: 多模态理解帮助图像创作接收更丰富的上下文
:width: 100%

参考信息和自然语言上下文让创作过程更接近沟通，而不是只写关键词。
```

```{figure} images/scene02_img03_images25.png
:alt: 可控创作强调参考、修订和输出复用
:width: 100%

可控工作流的价值在于让每次修改都有明确目标和可检查的结果。
```

```{figure} images/scene03_img01_precision_edit.png
:alt: 局部编辑只改变指定区域并保留其余画面
:width: 100%

局部编辑应明确区域、要改变的属性和必须保持不变的元素。
```

```{figure} images/scene03_img02_consistency_speed.png
:alt: 主体一致性和迭代速度需要通过参考与复核平衡
:width: 100%

主体一致性不能只凭感觉判断，应对照参考图检查外形、配色、构图和文字。
```

```{figure} images/scene04_img01_sketch.png
:alt: 草图作为构图和布局约束输入
:width: 100%

草图先锁定布局，再让模型填充细节，可以减少构图返工。
```

```{figure} images/scene04_img02_templates.png
:alt: 模板复用让多次创作保持统一结构
:width: 100%

模板把稳定的版式和品牌元素固定下来，避免每次从零描述。
```

```{figure} images/scene04_img03_comment_share.png
:alt: 评审批注和分享复用构成多人视觉协作流程
:width: 100%

评审意见应写成可执行修改项，并保留版本和来源以便复用。
```

```{figure} images/scene05_img01_flare.png
:alt: 光效等局部视觉元素需要与主体和构图一致
:width: 100%

局部特效必须服从主体、文字可读性和整体构图，而不是单独追求醒目。
```

```{figure} images/scene05_img02_sunburst.png
:alt: 背景与局部装饰修改的示例
:width: 100%

每次修改后检查是否意外改变人物、产品、文字或原有视觉层级。
```

```{figure} images/scene06_img01_boundaries.png
:alt: 图像创作中的版权、人物、文字准确和人工验收边界
:width: 100%

生成结果发布前仍需人工检查文字、版权、人物授权、误导性表达和品牌使用边界。
```
