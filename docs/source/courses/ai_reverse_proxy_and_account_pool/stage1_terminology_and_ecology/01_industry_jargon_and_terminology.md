# 01. 行业黑话、灰产生意链分工与倍率计价全景词典

在大模型中转站、海外号池与 API 聚合圈子中，黑话不仅是地下交易的“行业暗号”，更是一张**精密的分工表与风险转移机制**。号商与中转站市场水极深，许多看似诱人的“低价无限次”背后隐藏着模型掺水、信息泄露与突发风控封停。

本节系统拆解账号分类、灰产供应链四层分工、Claude 渠道体系及最核心的“倍率”计费算法。

---

## 一、账号生态分类黑话全景

| 术语名称 | 核心特征与生产方式 | 稳定性与存活期 | 适用场景与风险评级 |
| :--- | :--- | :--- | :--- |
| **手工号 (Handmade)** | 人工使用真实海外家宽 IP、原生浏览器、独立手机卡/邮箱逐个注册验证。 | 极高（几个月至数年） | ⭐️ **高推荐**：适合作为高可用号池的主力 Plus 账号或企业生产基建。 |
| **机刷号 (Bot/Script)** | 使用自动化脚本（如 Python Playwright）结合接码平台和批量代理并发生成的账号。 | 极低（极易在 24~72 小时内被风控清算） | ⚠️ **高危**：号商常用其冒充“手工新号”低价倾销，批量封号率高达 80% 以上。 |
| **成品号 (Ready-Made)** | 已经完成邮箱注册、手机号短信验证，交付时直接包含账密或包含绑定邮箱的完整账号。 | 中 ~ 高 | 适合开箱即用，但必须第一时间确认是否包含辅助邮箱所有权并修改密码。 |
| **纯净号 (Clean Account)** | 注册后从未绑定过可疑支付方式、从未在脏 IP 上登录、无任何滥用对话记录的一手白号。 | 极高 | 适合后续长期绑定正规苹果礼品卡或个人外币卡开通 Plus 会员。 |
| **独享号 (Exclusive)** | 一人一号，拥有全部所有权（邮箱账号、密码、Token 凭证均归买家独享）。 | 高 | 生产级反代号池唯一推荐的采买形态，杜绝多方并发争抢速率限制。 |
| **共享号 (Shared)** | 一号多卖，多位陌生人共用同一组账密或同一个 Session Token。 | 极低 | 严禁用于生产号池！容易遭遇历史对话隐私泄露、频繁撞 429 限流与随时被改密踢出。 |
| **直登号 (Direct Login)** | 交付形式为标准账号密码（如 `user@gmail.com:password`），买家可在网页端或官方 App 直接登录。 | 取决于注册质量 | 适合普通用户个人在桌面端直接交互使用。 |
| **授权号 / JSON 凭据号** | 不交付明文密码，直接交付提取好的 OAuth 凭据（包含 `access_token`、`refresh_token` 等）。 | 取决于底层账号 | ⭐️ **反代必备**：直接注入 CLIProxyAPI、One-API 或自动化中转引擎。 |
| **白嫖号 / 日抛号 (Disposable)** | 利用平台新人试用政策或漏洞生成的极短寿命账号，预期寿命仅 1~3 天。 | 极低 | 仅适合本地轻量冒烟测试，切勿用于生产。 |
| **绑卡号 (Carded Account)** | 号商通过海外虚拟卡（甚至黑卡/料卡）强行开通绑定的扣费账号。 | 极低（随时被 Stripe 拒付反洗钱封杀） | 🚨 **绝对禁区**：账号秒封且出口 IP 被拉黑。 |
| **降级号 (Degraded)** | 官方虽未注销账号，但命中风控后剥夺 GPT-4/Opus 权限，强制降级为 mini 或 3.5。 | 废品 | 需通过模型探测接口校验输出特征，警惕号商以高价售卖被阉割的降级号。 |
| **车头 / 车员 (Carpool)** | 拼车合租体系的术语。**车头**为账号所有者兼付款人；**车员**为分摊费用的合租者。 | 中等 | 若车头跑路或某位车员触发滥用，全车连坐。 |
| **翻车 / 拉闸 / 掉顶 (Revoked)** | 订阅中断或被 OpenAI/Anthropic 官方撤销会员权限（Refunded/Revoked），退回免费状态。 | 权益失效 | 常见于劣质充值卡、黑卡拒付后官方发起的退费与冻结惩罚。 |

## 二、大模型灰产生意链的四层分工与风险转移机制

大模型账号与 Token 买卖本质上是一条精密的地下产业链：

```{mermaid}
flowchart TD
    subgraph Level1 [第一层：上游生产商]
        P1["批量自动化脚本 / 虚拟支付 / 漏洞薅羊毛"]
        P2["理论毛利率: 15%~75% | 成本利润率: 18%~300%+"]
        P3["痛点: 承担极高风控突发清算成本，普通人最不适合"]
    end

    subgraph Level2 [第二层：渠道经销商]
        W1["自建发卡网 / 掌握直接货源 / 靠周转走量"]
        W2["单号毛利: 1~4 元 | 毛利率: 20%~40%"]
        W3["痛点: 资产为货源与客户池，夹在中间承担大量售后"]
    end

    subgraph Level3 [第三层：终端分销商]
        R1["闲鱼 / 小红书 / 微信社群终端接单"]
        R2["以卖养用 / 赚取小额信息差与平台流量"]
        R3["优势: 门槛最低，适合普通开发者补贴个人算力成本"]
    end

    subgraph Level4 [第四层：终端消费者 / 买家]
        C1["买到 80%~95% 的账面省钱率"]
        C2["实质: 买下的是整条产业链沉淀的所有不确定性"]
        C3["风险: 日抛、拉闸 401、隐私泄露、数据被中间人监听"]
    end

    Level1 -->|批发低价货源| Level2
    Level2 -->|API化/卡密封装| Level3
    Level3 -->|零售交付| Level4
```

### 1. 成本与利润真实账本
- **上游生产商**：假设邮箱成本 0.1 元，支付账户成本 16 元，若产出 10 个号单号成本 1.7 元，卖 4 元毛利率 57.5%。看似暴利，但一旦官方封堵接口或支付失效，毛利瞬间变负；
- **分销商（普通人最佳切入点）**：不囤货、低库存、低承诺。比如 5 元拿货，10 元在二手平台卖出，毛利率 50%，扣除售后和损耗，能有效通过平台流量“以卖养用”，抵消个人开发消耗；
- **客户的代价**：客户以为省了 90% 的钱，实际上买到的是一张“风险概率券”。

## 三、Claude 与 AI 编程工具中转核心术语解析

针对目前代码开发与 Agent 核心主力 Claude（Sonnet 4.6 / Opus 4.6）市场，市面上存在五种截然不同的上游渠道：

```{mermaid}
graph LR
    subgraph Channels [Claude 渠道全景]
        C1["1. 反代渠道 (逆向 Kiro / Antigravity / Cursor)"]
        C2["2. 官转渠道 (官方 Max / Team / Pro 转卖)"]
        C3["3. AWS 官渠 (Amazon Bedrock 官方企业接入)"]
        C4["4. 官方原生 (Anthropic 原生 API / Max)"]
    end
    
    C1 -->|极致便宜 0.2~0.3倍率| R1["有 System Prompt 污染 / 搜网失效 / 易断流"]
    C2 -->|性价折中 0.5~0.8倍率| R2["接近原生体验 / 满血推理"]
    C3 -->|企业级 1.0+倍率| R3["合规稳定 / 无污染 / 具备企业 SLA"]
    C4 -->|原价 1.0倍率| R4["最纯净最贵"]
```

1. **反代（Reverse Proxy / 逆向渠道）**：不走官方 API，而是逆向破解第三方 AI 编程工具（如 AWS Kiro、Google Antigravity 反重力、Cursor、Windsurf）的内部鉴权接口转卖额度。虽然便宜，但商家通常在底层强制注入原工具的 system prompt，造成**提示词污染（带私货）**，且 Web Search 功能多半失效；
2. **Kiro / 反重力（Antigravity）**：亚马逊与 Google 推出的 AI 编程基础设施，常被逆向黑产作为免费或廉价额度来源；
3. **官转（官方转卖）**：商家正规订阅 Claude 官方 Max/Team 账号，利用网关合法池化对外分发，体验最接近原生；
4. **AWS 官渠（Amazon Bedrock）**：通过 AWS 企业云直接调用的 Claude 原生接口，合规性与 SLA 达到最高等级；
5. **Max（Claude Max）**：Anthropic 面向高阶开发者的官方顶配订阅通道。

## 四、中转站核心“暗号”：倍率（Multiplier）全解析与真实计费公式

“倍率”是中转站圈内最核心、水分最深的计费暗号。

### 1. 什么是倍率？
**倍率 = 相对于官方 API 原生价格的乘数系数**。
- `1.0 倍率`：完全按官方原价扣费（最干净透明）；
- `0.5 倍率`：官方原价的 50%（常见于优质官转/满血号池）；
- `0.2 ~ 0.3 倍率`：官方原价的 20%~30%（典型纯反代逆向渠道）。

### 2. 生产真实费用计算公式（终极避坑）
中转站的实际扣费必须用以下公式综合计算：

$$\text{实际花费 (RMB)} = \text{官方 USD 价格} \times \text{基础倍率} \times \text{补全/分组倍率} \times \text{充值汇率}$$

- **充值汇率**：大多数中转站采用“1 元人民币 = 1 刀虚拟额度”（即 1:1 虚拟汇率）。部分低价站会写成 0.8:1；
- **官方参考基准单价（百万 Tokens）**：
  - **Sonnet 4.6**：输入约 $\$3$ / M，输出约 $\$15$ / M（输出通常是输入的 3~5 倍）；
  - **Opus 4.6**：输入约 $\$5$ / M，输出约 $\$25$ / M；
- **分组倍率 / 补全倍率陷阱**：部分不良中转站宣称“全场 0.3 倍率”，但在后台偷偷对输出 Token 叠加了 3 倍补全倍率，或对非 VIP 用户强制加征 1.5 倍分组倍率，导致实际扣费与原价无异。

````{admonition} 采购选型黄金法则
:class: tip

- **买前必查三件事**：倍率是多少？输入/输出是否分开计费？是否有额外分组或补全倍率？
- **切勿轻信“0.1 元一刀无限量”**：这类低价站 99% 会在后台暗中降级（把 Opus 偷换成小模型或开源模型），甚至记录窃取你的业务源码。
````
