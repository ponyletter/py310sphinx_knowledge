# 02. 号商发卡网生态剖析与 AI 号探测器实战

在大模型号池的采买与扩容环节，许多开发者会接触到各类自动化“发卡网”（即自动化发货虚拟商品交易平台）。由于市场缺乏监管，充斥着倒买倒卖、以次充好、以机刷冒充手工号的现象。本节深入剖析发卡网底层机制，并以行业探测工具与真实平台为例，传授专业级采购避坑技巧。

---

## 一、AI 号商生态与发卡网运作原理

```{mermaid}
flowchart TD
    Supplier["上游号商 / 自动化流水线<br/>(批量接码/家宽注册/开通Plus)"] --> CMS["发卡系统 (如独角数卡/ZFAKA等)<br/>自动化库存管理 & 支付网关"]
    CMS --> Aggregator["AI 号探平台 (如 aihaotan.com)<br/>全网爬虫聚合 & 价格库存探测器"]
    Aggregator --> Buyer["买家 / 开发者<br/>(比价检索/甄别信誉/自动化采购)"]
    Buyer --> CardDelivery["发卡网自动下发卡密<br/>(账号密码:辅助邮箱 / JSON凭据包)"]
```

发卡网（通常基于开源系统如独角数卡、ZFAKA 等二次开发）是虚拟商品自动化交付的枢纽：
1. **自动化入库**：号商将批量生产的账号卡密（以逗号或冒号分隔）批量导入发卡网后台；
2. **免登录扫码支付**：买家无需实名注册，输入查询密码或邮箱后直接通过微信、支付宝或 USDT 付款；
3. **即时卡密交付**：支付回调成功后，系统自动弹出卡密或自动发送至买家邮箱。

## 四、海外手机号注册与接码平台深度实战

在大模型账号批量生产与号池扩容中，**手机号短信验证（SMS Verification）** 是仅次于干净原生 IP 的核心风控门槛。特别是在 **OpenAI Codex OAuth 开发者凭据提取** 与新账号注册场景下，官方强制要求绑定已通过海外短信验证的手机号。若使用已被滥用的号码池或被标记的纯虚拟 VoIP 号段，会直接触发 `It looks like this is a virtual phone number (VoIP)` 拦截或导致账号秒封。

下面对主流的 10 大接码平台及解决方案进行深度技术分类、特性横评与实战选型指南。

### 1. 国际主流付费接码平台（生产首选 · API 自动化 · 自动退款）

此类平台号码库最庞大、覆盖全球 100+ 国家，支持按目标服务（OpenAI、Claude、Telegram 等）精细化筛选，且普遍具备**“在规定时间内（通常 15~20 分钟）未收到验证码自动退款至账户余额”**的健全保障机制。

1. **[SMS-Activate](https://sms-activate.org/cn)**
   - **定位**：全球规模最大的老牌接码巨头，中文支持完善。
   - **核心特性**：覆盖 170+ 国家，专为 OpenAI / ChatGPT 设立了独立项目通道；提供按次接码（Activation）与长期号码租用（Rent）；支持高并发 RESTful API，是编写自动化批量注册脚本的行业标准底座。
   - **支付支持**：微信/支付宝（通过聚合通道）、银行卡、加密货币（USDT/TON 等）。
   - **技术建议**：注册 OpenAI 时优先避开印尼、印度等被大量脚本薅秃的极低价号段，选用巴西、菲律宾、智利或东欧等成功率更高的国家。

2. **[5SIM](https://5sim.net/zh)**
   - **定位**：老牌俄罗斯接码服务商，以**极致性价比**与**运营商精细筛选**著称。
   - **核心特性**：除国家与应用服务外，支持精确选择特定电信运营商（如 Tele2、MegaFon、Beeline 等）。当某个运营商号段被 OpenAI 批量拉黑时，可在 5SIM 后台无缝切换其他运营商；同样提供健全的标准 API 与未收到短信自动取消退款机制。
   - **支付支持**：加密货币、电子钱包、国际信用卡。

3. **[Tiger SMS](https://tiger-sms.com/)**
   - **定位**：高稳定性的国际虚拟号与实体号批发零售平台。
   - **核心特性**：界面轻量清爽，中文本地化极佳；拥有大量亚洲、欧美专属号码池，针对 OpenAI、Claude 的验证码到达率高；支持单次快速接码与大规模 API 采购。
   - **支付支持**：加密货币、主流国际在线支付方式。

4. **[SMS-Man](https://sms-man.com/)**
   - **定位**：老牌多语言跨国接码平台，兼具虚拟号与长期租赁业务。
   - **核心特性**：支持 200+ 国家及上千款应用服务，支持多平台一键切换；提供完善的开发者文档与全功能 API，系统支持一键自动更换不可用号码。
   - **支付支持**：支付宝、微信支付、银联、USDT 等，国内开发者入金门槛低。

5. **[SMS-Activation-Service](https://sms-activation-service.com/)**
   - **定位**：面向开发者和自动化营销的专业级全自动接码平台。
   - **核心特性**：提供极其规范的自动化 API，系统响应延迟低，非常适合集成进无头浏览器（Puppeteer/Playwright）注册工作流；号码更新频率高，涵盖欧美与独联体主流国家。
   - **支付支持**：主要支持加密货币与主流国际电子钱包。

6. **[OnlineSIM](https://onlinesim.ru/v2/receive/sms)**
   - **定位**：欧洲老牌号码接收服务商。
   - **核心特性**：提供大量独享号码与可反复接收验证码的重复租用通道，适合某些阶段性需要复验二次验证码的特殊账号体系。

### 5. 一次性临时接码 vs 长期保号方案决策

在号池全生命周期维护中，接码仅是第一步，后续的账号可持续性至关重要：

1. **一次性接码 (Disposable SMS)**：
   - **成本**：单次仅需 0.1~0.5 美元，成本极低；
   - **缺陷**：短信接收窗口仅 15~20 分钟，号码随后被上游卡商回收。若后续 OpenAI 触发罕见的登录安全复验或强制开启 2FA 双重认证，该账号将彻底失联报废；
   - **适用场景**：大规模 Free 额度消耗号、短期高并发实验号池。
2. **长期租用号码 (Long-term Rental)**：
   - **成本**：按周或按月包养号码（通常每月 5~15 美元）；
   - **优势**：可在租用期内持续接收同一个号码的多条短信，保障账号安全等级；
   - **适用场景**：团队核心主账号、重要项目的专属开发账号。
3. **终极解决方案：海外物理实体卡 / 独立 eSIM（高净值账号首选）**：
   - **英国 giffgaff 实体 SIM 卡**：国内可免费申请（或发卡网十几元包邮采买），国内直接插卡漫游，在中国大陆支持免费接收全球短信，每 180 天仅需发一条 0.3 英镑的短信即可永久保号；
   - **美国 Ultra Mobile PayGo 实体卡**：月租 3 美元，享有原生真实的美国移动运营商物理号码，权重极高，能完美绕过所有 VoIP 侦测；
   - **5ber / RedteaGO 实体转接 eSIM 卡**：配合支持 eSIM 的设备，可随时随地购买并切换不同国家的数据与短信套餐；
   - **核心价值**：拥有真实电信运营商的基站信令与 IMSI 物理属性，被识别为最高信任级终端，一劳永逸解除验证码风控。

## 五、国内代采渠道（淘宝 / 闲鱼）与 WildCard 现状通告

### 1. 重要提醒：WildCard (野卡) 已正式停止运营
过去国内开发者常用的海外虚拟卡服务 **WildCard（野卡）目前已正式发布公告停止运营**。切勿轻信互联网上的任何野卡注册或充值链接，谨防钓鱼网站与诈骗仿冒！

### 2. 淘宝 / 闲鱼代充代购的鉴别法则
许多开发者在没有海外支付手段时会转向淘宝或闲鱼代购：
- **谨防“先确认收货再充值”的骗术**：许多黑产号商使用被盗信用卡（料卡）为你完成 Plus 充值，诱导你提前确认收货。3~5 天后真实持卡人发现被盗刷并向银行发起拒付（Chargeback），OpenAI 会立即撤销 Plus 权限（翻车掉顶）并封停你的账号，此时淘宝订单已过维权期。
- **要求对方使用苹果官方礼品卡收据充值**：在淘宝或闲鱼找代充时，要求对方必须提供官方 Apple Store 礼品卡购买凭证与充值兑换截图。

## 六、发卡网采购防坑黄金准则

````{admonition} 严防“低价陷阱”与“假手工真机刷”
:class: warning

1. **切勿贪图远低于官方成本的超低价**：ChatGPT Plus 官方按月收费 20 美元（约合人民币 145 元左右）。若发卡网标价仅 30~50 元且声称“独享一个月”，其背后 99% 是被盗黑卡（几日内必翻车封号）或是多卖的伪独享车位。
2. **优先采买“带完整邮箱控制权”的成品号**：交付卡密若仅有 ChatGPT 账号密码而没有邮箱登录权限，一旦触发登录邮箱验证码校验，账号将彻底失联。
3. **严格检验 JSON 凭据中的 `refresh_token`**：部分不良号商交付的 JSON 只有短期 `access_token`。一旦数小时过去 Token 过期，号池将直接不可用。
4. **小批量试采验收，切忌大批量压货**：首次合作号商，先采买 1~2 个账号放入反代池压测 48 小时，确认未遭遇大规模批量封停后再考虑批量采购。
5. **到手即测：利用脚本探测是否为“降级号”**：通过向该账号发起高阶模型推理请求，比对返回的特征字段，严防被号商以 GPT-3.5/mini 冒充高阶大模型。
````
