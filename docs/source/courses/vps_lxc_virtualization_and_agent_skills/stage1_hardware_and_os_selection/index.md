# 阶段一：宿主机选型基准、内核评估与操作系统实测

> **掌握海外 VPS 硬件规格配比、底层 KVM 虚拟化校验、内核 BBR 拥塞控制模块排查，以及跨操作系统发行版（Debian 13 vs Ubuntu 24.04/22.04）的真实内存与磁盘开销实测。**

---

## 阶段导读

在启动任何容器化部署与代理服务之前，**“地基”的质量决定了整座架构的稳定性上限**。许多开发者在廉价 VPS 上遭遇容器无法启动、网络转发丢包严重或拥塞控制算法无法开启的问题，其根本原因往往出在宿主机的底层虚拟化架构（如 OpenVZ / LXC 嵌套受限）、精简内核缺少 BBR 模块、或者选用了已停止维护的过时操作系统发行版。

本阶段将系统性梳理高可用 VPS 宿主机的选型准则，并基于真实云端环境的自动化 CI 评测数据，为你呈现各主流操作系统在空载、LXD 容器集群部署后的真实资源基准线。
