# 2.3 高价值提示词工程（Prompt Engineering）精选速查

> **核心导语：** 汇集在日常开发、文本润色、代码重构、竞品调研中经过反复验证的高效提示词模版。

---

## 📌 提示词分类速查表

| 应用场景 | 核心设计技巧 | 适用模型 | 预期效果 |
| :--- | :--- | :--- | :--- |
| **深度代码 Review** | 严格指出潜在内存泄漏与并发风险 | Claude 3.5 Sonnet / o1 | 极致严谨的 Bug 排查 |
| **技术文档撰写** | 结构化拆解 + 行业标准排版 | GPT-4o / Claude | 直接可发布的讲义格式 |
| **复杂逻辑推演** | 逐步思考 (Chain of Thought) | o1 / DeepSeek-R1 | 逻辑零漏洞的决策树 |
