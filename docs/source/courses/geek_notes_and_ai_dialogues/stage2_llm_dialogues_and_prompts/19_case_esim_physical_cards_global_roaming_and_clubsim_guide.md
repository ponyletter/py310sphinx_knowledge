## 📌 背景与数字基建痛点：国行机与海外数字身份的断层

在当今出海业务、独立开发与全球化数字协作（如注册与使用 OpenAI ChatGPT、Claude、Telegram、WhatsApp、港美股券商、海外银行与跨境支付工具）中，**拥有一个稳定合规的海外真实手机号码，以及具备全球漫游能力的通信通道**已成为基础设施层面的刚需。

然而，国内开发者普遍面临三大结构性鸿沟：
1. **硬件层断层（国行机无原生 eSIM）**：
   - 中国大陆发售的国行 iPhone（自 iPhone XR/XS 以来全系双 Nano-SIM 物理卡槽）以及绝大多数国产安卓机型，均在硬件或固件层面禁用了 eSIM 芯片，无法直接扫描运营商提供的 eSIM 二维码；
2. **号码层断层（虚拟号易风控，实体号成本高）**：
   - 使用接码平台（SMS-Activate 等）的虚拟号极易触发风控导致封号；购买海外纯实体 SIM 卡不仅国际转运周期长（数周至数月）、运费昂贵，还常面临 SIM 卡年费高、国内漫游失效等问题；
3. **网络层断层（跨境访问延迟与合规风险）**：
   - 纯依靠境外 VPS 代理访问时，遇到复杂多跳网络经常遭遇 IP 连带风控与验证码轰炸；而出差落地时需要纯净、合规的国际原生出口网络。

## 🪪 eSIM 转实体卡（eUICC 可复写卡）主流硬件全景横评

### 1. 核心运行原理与架构名词解密

为了不被市场各种花哨噱头误导，必须先厘清背后的技术规范：
- **eUICC (Embedded Universal Integrated Circuit Card)**：符合 GSMA 国际电信标准的智能卡硬件，具备在同一硬件芯片上安全存储并按需切换多个运营商通信配置（Profile）的能力；
- **Profile (配置文件)**：由运营商通过 SM-DP+ 服务器签发的数字化 SIM 卡，包含 IMSI、密钥 Ki、卡号及网络接入参数；
- **LPA (Local Profile Assistant)**：负责在手机本地与运营商远程 SM-DP+ 服务器通信、下载并写入 Profile 的核心软件栈。
- **STK (SIM Application Toolkit) 菜单**：手机系统内置的“SIM 卡应用程序”入口，用户无需安装任何 App，直接在系统原生菜单内就能向实体卡发送切换指令。

## 📶 中国大陆可用 eSIM 漫游流量套餐深度横评（免翻墙直连）

### 1. 漫游免翻墙原理：国际漫游数据回传架构

很多初学者疑惑：为什么在中国大陆使用某些海外 eSIM 流量，手机可以**免任何代理客户端直接秒开 Google、ChatGPT、Claude、Twitter 与 YouTube**？

其底层通信架构如下：

```{mermaid}
sequenceDiagram
    autonumber
    actor Phone as 国行手机 (插eSIM实体卡)
    participant Tower as 中国移动/联通基站 (SGSN/MME)
    participant IPX as 国际漫游网络通道 (IPX)
    participant HomePGW as 境外归属地网关 (GGSN/P-GW)
    participant Target as 目标外网 (Google / OpenAI)

    Phone->>Tower: 发起蜂窝数据连接请求 (APN 漫游鉴权)
    Tower->>IPX: 封装 GTP 隧道数据包，出境传输
    IPX->>HomePGW: 交付至香港/新加坡本地运营商核心网
    Note over HomePGW: 核心网解包，分配原生境外住宅/商业 IP
    HomePGW->>Target: 以境外原生 IP 直接访问互联网 (完全绕过 GFW)
    Target-->>HomePGW: 返回数据
    HomePGW-->>IPX: 漫游回传
    IPX-->>Tower: 到达国内本地蜂窝接入点
    Tower-->>Phone: 毫秒级展示国际网页内容
```

- **免墙原理**：国内运营商基站仅作为“传输管道（Bit-pipe）”，数据通过加密的 GTP 隧道直接路由至海外归属地运营商（如香港、新加坡）的 P-GW 出口，故无需翻墙且不经过 GFW 内容审查；
- **合规与实名**：国际漫游遵循双边漫游协议，无需在中国大陆进行国内实名登记，隐私保护极强。

### 第 3 章　把 eSIM Profile 写入手机或实体卡

#### 方案 A：原生支持 eSIM 的手机（外版 iPhone / Android）
1. 连上 Wi-Fi 网络；
2. 依次进入：`系统设置 → 蜂窝网络 → 添加 eSIM → 扫描二维码`；
3. 对准邮件中的二维码扫描，按提示添加标签（如命名为“香港 852”）；
4. ⚠️ **激活期限**：自购买日起 **365 天内**必须扫码激活，逾期二维码将自动作废失效。

#### 方案 B：国行 iPhone + 实体卡方案（以 ESTK / BeeSIM 为例）
1. 将 ESTK / BeeSIM 实体卡插入国行 iPhone 主卡槽；
2. **BeeSIM**：打开微信小程序搜索卡片配套工具，蓝牙直连卡片，扫描邮件中的二维码即可将 Profile 写入芯片；
3. **ESTK / 9eSIM**：使用配套读卡器在电脑端或通过安卓机使用开源 LPA 工具将 Profile 烧录入实体卡，完成后插回国行 iPhone，直接在“设置 → 蜂窝网络 → SIM 卡应用程序”中点击激活。

**铁律警告**：eSIM 配置文件一旦成功下载绑定设备，**严禁在系统设置中点击“删除 eSIM”**！一旦误删，手机将彻底失去与该卡片的物理关联，必须致电 Club Sim 人工客服（+852 1833123）并提供 CLS 订单号申请补发，流程繁琐。

### 第 4 章　香港法律强制实名登记（RNR）实操流程

根据香港《电讯（登记用户识别卡）规例》，所有香港预付 SIM 卡必须在启用前完成真实身份实名核验（Real-name Registration, 简称 RNR），未实名的卡无法进行收发短信和通话。

```
[收到欢迎短信] ──> [点击加密实名链接] ──> [注册 Club Sim 邮箱账号]
                                                    │
[重启手机启用服务] <── [收到确认短信] <── [手机相机扫描证件原件]
```

1. **接收实名入口**：
   - eSIM 写入成功并开机后，手机将在数分钟内自动漫游注册至中国移动或中国联通网络，并收到 Club Sim 发来的欢迎短信；
   - 短信中包含专属中文实名登记链接（格式如：`rnr.hkcsl.com/clubsim?iccid=89852...&lang=zh`）；
2. **账号绑定与证件核验**：
   - 点击链接进入，选择**“新客户”**；
   - 使用下单邮箱注册 Club Sim 个人账号并设定高强度密码；
   - **切换至手机端实操**：若在电脑端打开，页面会生成二维码，需用手机相机扫码并在手机浏览器内继续；
   - 证件类型选择**“中国护照”**或**“港澳通行证”**；
   - 按照页面动态取景框，平放证件原件并实时拍照，避免强光反光与阴影遮挡；
3. **提交与即时生效**：
   - 系统 OCR 自动识别并核对姓名拼音与护照号无误后，点击提交；
   - 通常 3~5 分钟内即会收到确认短信：“*You have completed the real-name registration*”；
   - 收到短信后**重启手机**，该卡即可正式正常收发短信。

- **日常状态**：无需维持任何卡内余额，放在手机内**免费接收全球短信验证码**；
- **定时提醒机制**：建议在日历中，将提醒时间设定在开卡后的**第 10 个月**（即预留 60 天安全余量）；

## 🚨 常见问题排查与避坑指南

### Q1: 没有境外实体信用卡，怎么支付开卡费？
- 实测使用主流加密虚拟卡（如 [RedotPay 虚拟 Visa 卡](../stage2_llm_dialogues_and_prompts/15_case_crypto_payment_cards_and_redotpay_onchain_guide.md)）可 100% 成功结算港币；
- 若无外币卡，Club Sim 结账页目前亦支持**支付宝（Alipay）与微信支付（WeChat Pay）**作为兜底通道。

### Q2: 为什么拨出电话时有长串粤语/英语语音提示？
- 这是香港通讯事务管理局（OFCA）对本地预付储值卡的法定要求：新启用的储值卡在初次向外拨打时会有合规提示语音，属于正常现象，无需理会，挂机后即可正常接听。

### Q3: 实体卡丢失或手机损坏，已下载的 eSIM 还能挽救吗？
- 如果使用的为 **9eSIM / ESTK Max** 等可复写卡，更换手机只需拔出该物理卡插至新设备即可无缝迁移；
- 若为原生写入 iPhone 固件的 eSIM，若换新机需联系客服重新下发二维码；故极其建议将订购确认邮件中的 **CLS 号码与订单凭证**妥善保存在密码管理器中。
