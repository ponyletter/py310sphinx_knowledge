# 【实战复盘】周行：Codex 自动化剪辑从 0 到 1——电商带货视频日产由 6 条提升至 30 条

> **案例作者**：周行（周行今天学习了吗？）  
> **作者背景**：主业资深电商操盘手，副业专注于 AI 自媒体与自动化剪辑  
> **核心标签**：`自动化剪辑` `电商千川带货` `FFmpeg镜头拆解` `视觉相似度匹配` `剪映草稿引擎` `AGENTS.md` `Skill封装`  
> **实战指标**：618 大促期间单日视频产量由手动 6 条跃升至 30 条（效率提升 5 倍），跑量爆款素材带来近千笔真实订单  
> **关键洞察**：自动化剪辑的核心定位是工业化批量生产，而非替代高端艺术创作。素材库质量决定了自动匹配的上限；宁可标记“缺素材”交由人工补充，也绝不用无关素材硬凑。把反馈与边界写进 `AGENTS.md` 并封装为 Skill，是实现长效自动化的关键。

## 一、自动化剪辑的底层定位与适用场景

不管是内容传播还是电商跑量，最快拿到确定性结果的方式是**研究并复刻已经过市场验证的爆款结构**：
- **传统复刻痛点**：在剪映中对照爆款视频一帧帧打点、翻找素材、对字幕、调配音，耗费 2~3 小时才产出 1 条；
- **Codex 方案**：输入对标参考视频与自有素材库，AI 自动识别镜头切换、视觉匹配最佳素材、调用大模型合成配音、生成精准字幕，最终直接输出一个**可二次微调的剪映原生草稿**（耗时仅数分钟）。

```{warning}
**生产定位红线**：
本工作流专为**多镜头片段拼接的混剪/硬广/带货视频**设计（如千川信息流素材、图书带货、好物开箱）。对于依赖极其细腻的情绪张力、复杂转场与深度人文叙事的精品原创视频，AI 当前的语义理解与节奏把控尚无法完全替代人工。
```

## 二、工作流前期准备与运行环境配置

### 2.1 依赖工具与库
1. **FFmpeg**：音视频底层切分、帧提取、格式转换的核心依赖（必须）；
2. **Python 3.8+**：运行环境，依赖 `opencv-python`、`numpy`、`pillow`；
3. **配音方案**：字节跳动豆包语音大模型（剪映同源音色，1 分钟短视频成本约 0.4~0.8 元）或开源的声音克隆工具 VoxCPM；
4. **剪映专业版**：承接最终生成的草稿项目。

#### 一键环境自检 Prompt
```text
请帮我检查视频自动化剪辑所需的基础环境：
1. 检查 FFmpeg 是否已安装并在系统 PATH 中，若未安装请给出平台对应的安装命令；
2. 检查 Python 版本是否 >= 3.8；
3. 检查本机是否安装了剪映专业版；
4. 检查并安装 Python 依赖包：pip install opencv-python numpy pillow
检查完毕后，明确告诉我哪些已就绪，哪些需要我手动确认。
```

## 三、四大核心剪辑工序与自动化提示词套件

```{mermaid}
flowchart LR
    S1["工序 1: 拆解参考视频<br/>(FFmpeg 关键帧切分 -> recipe.json)"] --> S2["工序 2: 视觉特征匹配<br/>(色彩/构图置信度打分 -> matches.json)"]
    S2 --> S3["工序 3: 豆包 TTS 语音合成<br/>(真实语音时长回写，拉伸视频节奏)"]
    S3 --> S4["工序 4: 生成剪映草稿<br/>(三大 ID 对齐，绝对路径锁定)"]
```

### 工序 1：拆解参考视频（生成机器可读的 `recipe.json`）
```text
我需要拆解一个参考视频，文件位置在：work/YYYY-MM-DD/reference.mp4

请帮我完成以下任务：
1. 用 FFmpeg 识别视频的镜头切换点（通过帧间差异度分析 scene cut）；
2. 为每个切分出来的镜头提取代表性关键帧，保存至 video_clips/ 目录下；
3. 提取视频的独立音轨，保存为 audio.mp3；
4. 自动生成核心的 recipe.json 文件，记录每个镜头的序号、起始时间戳、结束时间戳、时长与关键帧绝对路径；
5. 调用 ASR 提取原视频文案，按镜头切分对应段落，输出至 script.txt。
完成后告诉我共拆解出多少个镜头，让我确认切分合理性。
```

---

### 工序 2：筛选与智能匹配素材（置信度打分与宁缺毋滥原则）
```text
======================================================================
【素材库视觉特征匹配 Prompt】
======================================================================
我需要从素材库中匹配并替换参考镜头的画面素材。
输入配置：
- recipe.json 路径：work/YYYY-MM-DD/recipe.json
- 素材库根目录：assets/
- 输出目录：work/YYYY-MM-DD/material/

匹配执行规则：
1. 读取 recipe.json 中每个镜头的关键帧；
2. 遍历 assets/ 素材库中的所有视频，提取关键帧并建立特征向量；
3. 基于色调、主体明暗度、景别构图综合计算相似度，给出 0.0~1.0 的置信度得分；
4. 强制应用去机械化规则：
   - 避免连续 3 个镜头出现来自同一个子文件夹的素材；
   - 避免相邻镜头出现完全相同的背景房间或构图角度；
5. 【核心底线】：若某个镜头的匹配置信度低于 0.6，必须标记为“缺素材”，严禁用无关素材硬凑数量！
6. 将匹配成功的素材复制（严禁移动或重命名原素材）至 material/fragment01/、fragment02/ 目录中；
7. 输出 fragment_plan.json 与 matches.json，并列出待人工补充素材的镜头编号。
======================================================================
```

### 工序 3：生成高拟真配音并反向校准时间线
配音实际语速往往与原参考视频存在出入。作者设计的机制是：**以实际配音的时长作为视频轨道的绝对基准**：

```text
我需要为视频生成配音，文案文本位于：work/YYYY-MM-DD/script.txt

要求：
1. 调用豆包 TTS 接口，为每个镜头段落生成独立的音频切片；
2. 测量每个生成的音频片段真实时长；
3. 若配音时长与参考视频镜头时长存在偏差，自动以真实配音时长为基准，拉伸或填充该镜头的视频帧长度；
4. 拼接输出完整的主音轨：final_voice.mp3；
5. 回写 recipe.json，更新每个镜头的实际排版时长。
完成后输出试听音频，等待我试听确认语速与自然度。
```

### 工序 4：生成剪映草稿（三大 ID 防冲突铁律）

```{warning}
**剪映草稿格式踩坑防灾指南**：
剪映专业版对于草稿的 JSON 格式校验极为苛刻，一旦违反将导致“草稿损坏打不开”或“草稿覆盖丢失”：
1. **三大 ID 必须完全一致**：草稿中的 `content_id`、`metadata_id` 与 `root_index_id` 必须保持完全相同；
2. **全局唯一 UUID**：每次生成的草稿必须重新生成全新的 UUID，不可复用旧草稿 ID；
3. **绝对路径有效性**：草稿中引用的所有视频、音频和图片路径必须是**当前机器上的绝对文件路径**，且目标文件必须真实存在。
```

```text
我需要生成最终的视频工程与剪映草稿。
输入文件：
- recipe.json、matches.json、素材目录 material/、配音 final_voice.mp3、字幕文本 script.txt

输出交付：
1. 快速预览视频：work/remix.mp4
2. 外挂字幕：work/captions.srt
3. 剪映工程草稿：work/jianying_draft/

核心约束：
- 严格遵循剪映草稿协议：content_id、metadata_id、root_index_id 必须一致且全局唯一；
- 素材路径必须为绝对路径；
- 轨道以配音时间为准对齐，生成完毕后提醒我打开剪映审核。
```

## 四、完整的 AGENTS.md 规范与 Skill 沉淀

当一整套流程跑通后，作者将其抽象并固定为工作区根目录的 `AGENTS.md`：

```markdown
# 视频自动化剪辑系统配置文件 (AGENTS.md)

## 1. 项目核心目标
自动化接收参考视频与产品素材库，稳定输出符合抖音/视频号标准的剪映工程草稿，将单日剪辑产能提升至 30 条以上。

## 2. 输出工程规格
- 画布比例：9:16 竖屏（1080x1920，60fps）；
- 音频标准：使用豆包 TTS 生成的全新人声，剥离原参考视频声音；
- 字幕安全区：底部留出 25% 避开平台 UI 按钮，中部展示关键词字幕，行宽不超过 16 个中文字符；
- 审核验收：所有成片必须以剪映草稿形式交付，保留可编辑轨道供人工做最终音效与贴纸精修。

## 3. 验收合格标准
- 绝无无关素材硬凑；缺素材片段在报告中显式暴露；
- 剪映草稿双击即可在电脑剪映专业版中无错误加载；
- 画面、人声与字幕时间轴误差在 100ms 以内。
```

> **作者实战心法**：
> “把整套流程封装成 Skill 之后，日常剪辑只需要发一句话：`调用剪辑Skill，参考视频在@xxx.mp4`，去泡杯咖啡回来草稿就已经躺在电脑里了。创作者只需花 10 分钟在剪映里顺一遍、补上两处卡点音效与高光贴纸，一条充满网感的爆款带货视频就诞生了。”
