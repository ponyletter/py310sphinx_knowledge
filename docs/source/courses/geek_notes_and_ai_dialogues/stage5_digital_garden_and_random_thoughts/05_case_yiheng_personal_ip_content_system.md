## 一、 认知颠覆：为什么用了 AI 之后，内容反而越来越不像自己？

AI 让写文章变得极其便宜，几分钟就能出一篇结构规整的万字长文。但大多数创作者用了一段时间后，都会产生强烈的挫败感：**AI 生成的内容越来越多，但自己真正看得上、愿意公开发布的内容却越来越少。**

```text
💡 人味检验法：
把文章顶部的作者名字遮住，看同行能不能直接拿去发？
如果答案是“完全能”——它可能是一篇逻辑及格的科普，但绝不是你的个人 IP 内容。
```

这种“哪里都对，唯独不像我”的困境，根源在于创作者陷入了**四重错位**：

```{mermaid}
flowchart TD
    E1["1. 目标错位<br/>把'批量写稿'当目标，缺少商业承接与信任建立"]
    E2["2. 输入错位<br/>只给题目与空泛指令，未注入真实经历、踩坑事实与一手案例"]
    E3["3. 分工错位<br/>把立场、态度和判断推给 AI，人沦为复制粘贴工具"]
    E4["4. 闭环断裂<br/>发布即终结，评论私信与真实反馈从未回写系统"]
    
    E1 & E2 & E3 & E4 --> D["灾难结果：AI 只能产出'全人类的正确废话'"]
```

> **核心判断**：个人 IP 真正值钱的，不是公共知识，而是**“你经历过什么、你为什么坚持这个立场、你在哪次失败后修正了判断、面对利益抉择你做出了什么取舍”**。AI 负责效率，IP 负责信任，系统负责复利。

## 二、 个人 IP 内容系统的五层架构模型

一套成熟的内容系统不取决于用了多复杂的工具，而在于是否具备**稳定的输入、可重复的生产、以及结果的回流闭环**：

```
┌─────────────────────────────────────────────────────────────┐
│                    个人 IP 内容系统的五层金字塔               │
├──────────────┬──────────────────────────────────────────────┤
│ 1. 方向层    │ 目标人群、痛点场景、认知定位、商业转化承接    │
├──────────────┼──────────────────────────────────────────────┤
│ 2. 资产层    │ 经历故事、观点判断、项目案例、客户提问、历史数据│
├──────────────┼──────────────────────────────────────────────┤
│ 3. 认知层    │ 信息、故事与“个人判断规则”（什么做/坚决不做） │
├──────────────┼──────────────────────────────────────────────┤
│ 4. 生产层    │ 母题拆解 ➔ 调取真实资产 ➔ 生成框架 ➔ 人工定稿  │
├──────────────┼──────────────────────────────────────────────┤
│ 5. 反馈层    │ 完播率、评论高频词、创作体感、商业线索回流系统 │
└──────────────┴──────────────────────────────────────────────┘
```

## 三、 【核心资料】四大实操提示词完整收录

以下 4 套提示词是亦恒个人 IP 系统能够常年自动化运转的核心引擎，完整收录以便直接复用：

### 1. 个人 IP 内容系统盘点提示词

```text
你现在是我的个人IP内容系统诊断顾问。请帮助我盘点目前的内容创作方式，判断我的AI内容系统缺少哪些环节，并给出最小可执行的优化建议。

请围绕以下五层对我进行访谈：
1. 方向层：目标用户、核心问题、内容目标和业务连接是否清楚？
2. 资产层：是否积累了个人经历、观点、案例、用户问题、产品资料和历史内容？
3. 认知层：AI是否了解我的故事、立场、判断标准和表达边界？
4. 生产层：从素材、选题、创作到发布，是否有可重复的流程？
5. 反馈层：数据、评论、私信、创作体感和商业结果是否会回到系统？

访谈规则：
- 每次只问一个问题，根据我的回答继续追问。
- 要了解我的真实做法，不要根据理想流程替我补充答案。
- 区分“已经具备”“部分具备”和“尚未建立”。
- 不要一开始推荐复杂工具或自动化。
- 优先找到当前最影响内容生产的1—2个关键问题。
```

### 2. 个人 IP 背景提炼提示词

```text
你现在是我的个人IP战略定位与背景顾问。请基于我提供的人生经历、职业转型、创业经历和关键挫折，为我提炼一份标准的《个人IP背景说明书》。

请重点梳理以下板块：
一、我是谁与我的底色：
- 核心身份标签与从业年限；
- 决定我今天立场的核心转折点（人生关键选择）；
- 我犯过最大的错误及从中获得的底层认知。

二、我服务谁与不服务谁：
- 目标受众特征画像与最痛的3个核心场景；
- 明确的负向边界：坚决不服务哪类人群（如急功近利、白嫖伸手党）。

三、我的价值观与认知红线：
- 在我所在的赛道，我坚决反对什么潜规则；
- 无论发生什么，我都坚持的3条基本做事原则。

四、核心交付物与商业承接：
- 我的内容最终连接到什么后端产品或业务闭环。
```

### 3. 内容资产化提示词（将碎片资料转化为资产卡）

```text
你现在是我的个人IP内容资产整理顾问。我会提供一份原始素材，可能是线下录音、会议逐字稿、书籍笔记、学习文档、项目复盘、用户咨询或内容数据。你的任务不是立即写文章，而是把这份一次性素材，整理成可以被反复调用的《内容资产卡》。

请先读取：
1. 我的《个人IP背景说明书》
2. 本次提供的原始素材

处理时请遵守以下规则：
- 不得编造原始素材中没有的经历、数据和观点。
- 明确区分“客观事实”“素材原意”“我的判断”和“AI推断”。
- 找不到的信息标记为“待补充”，不要自行补写。
- 优先提炼与目标用户、内容方向和业务相关的信息。
- 暂时不要直接生成完整文章。

请按照以下结构整理：
一、素材信息
- 素材类型
- 素材来源
- 发生时间
- 核心主题
- 可信度与待确认信息

二、事实与原意
- 素材中明确出现的事实
- 原作者或原始表达的核心意思

三、提炼的方法与可复用经验
- 提炼出 1~2 个具有普适性的操作 SOP 或思考框架

四、延伸内容选题
- 基于此资产卡，可延伸出的 3 个不同平台爆款选题建议
```

### 4. 从内容机会到最小商业闭环设计提示词

```text
你现在是商业模式与个人IP变现顾问。请帮我评估目前内容机会与后端商业承接的闭环设计。

请严格根据以下逻辑推演：
1. 流量入口匹配度：这些内容吸引来的人群，是否有真实的付费意愿与预算？
2. 信任递进阶梯：从看到一篇公开笔记，到私域添加好友，需要跨越怎样的信任门槛？我给出了什么不可拒绝的“钩子”？
3. 交付承接交付力：当用户产生咨询后，我是否有标准化、低边际交付成本的产品（如社群、专栏、咨询或工作流模板）承接？
4. 商业飞轮闭环：如何让付费用户的真实反馈与成功案例，再次作为新素材回流至内容资产库？
```

## 四、 7 天搭建最小可用内容系统（MVP）SOP

新手搭建内容系统最容易踩的大坑，就是“内容一篇没写，先折腾搭了一堆复杂的文件夹和自动化工具，一个月后彻底烂尾”。

**7 天 MVP 核心原则：只验证一件事——能否把一份真实素材，稳定变成一条属于自己的爆款内容，并为下一次留下资产。**

```text
本地项目目录极简五大工作区：
├── 00-IP说明书/      # 核心定位、人设、价值观与禁忌
├── 01-原始素材/      # 录音逐字稿、读书笔记、咨询记录
├── 02-内容资产/      # 提炼好的标准《内容资产卡》
├── 03-选题与创作/    # 正在推进的文章大纲与初稿
└── 04-发布与复盘/    # 各平台发布记录、互动数据与复盘
```

### 每日任务拆解与交付物

- **第 1 天：确定边界**
  - 只定四件事：一个目标用户群体、一个核心痛点、一个主攻平台、一个阶段量化目标；
  - *交付物*：一张《个人 IP 目标卡》。
- **第 2 天：完成一页 IP 说明书**
  - 梳理信息、故事、判断三类内容，让 Codex 彻底搞懂你是谁、坚决不说什么废话；
  - *交付物*：一份存入 `00-IP说明书/` 的 Markdown 规范。
- **第 3 天：收集 5 份真实素材**
  - 翻找以前的项目复盘、微信群咨询记录、线下录音，用《内容资产化提示词》处理成 5 张标准卡；
  - *交付物*：5 份存入 `02-内容资产/` 的《内容资产卡》。
- **第 4 天：由素材反推选题与结构**
  - 严禁用空想去决定选题；基于已有的 5 张资产卡，让 AI 反推 3 个选题大纲；
  - *交付物*：一篇确定好的《文章框架与故事插入点》。
- **第 5 天：生成初稿并注入血肉**
  - AI 按照大纲生成初稿，创作者在关键段落手动插入自己当年的心理活动与失败细节；
  - *交付物*：一篇满意的待发布成品稿件。
- **第 6 天：排版并在一个平台真实发布**
  - 制作配图并在小红书或公众号完成真实发布，记录发帖时间与初始指标。
- **第 7 天：建立反馈与复盘飞轮**
  - 收集用户第一波评论与私信，将优质提问提炼为新问题卡，存入 `01-原始素材/`，完成闭环循环。
