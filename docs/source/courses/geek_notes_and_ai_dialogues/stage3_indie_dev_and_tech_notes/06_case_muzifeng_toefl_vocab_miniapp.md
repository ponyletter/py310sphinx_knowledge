## 一、为什么做背单词小程序？视觉具象记忆的力量

### 1.1 传统背单词的痛点
绝大多数考生在备战托福、雅思或四六级时，都陷入过“背了忘、忘了背”的死循环。纯文字词条对于人脑来说属于高度抽象的符号，缺乏情绪与场景锚点，遗忘速率极快。

### 1.2 视觉具象记忆（Visual Memory Anchor）
科学记忆法表明，**人脑对具象画面的记忆牢固度远超抽象文字**。

以托福核心词汇 `abort`（中止、夭折）为例：
- **纯文字模式**：反复默读“abort，a-b-o-r-t，中止，abort，中止” $\to$ 考场上大脑一片空白；
- **具象画面模式**：一艘倒计时即将点火升空的巨大火箭前，地面指挥中心的宇航员满头大汗、一巴掌狠狠拍下台面上巨大的红色「停止/ABORT」按钮，警报红光闪烁，白色冷却烟雾漫天喷涌。

只要这个夸张、戏剧性的画面在脑海中停留过 2 秒钟，下次看到 `abort`，大脑会瞬间提取出“拍按钮中止火箭”的场景，秒级还原词义。

```{mermaid}

    D["视觉模式: 具象画面 (火箭发射前宇航员拍下红色停止按钮)"] --> E["强视觉冲击 + 情绪记忆"] --> F["神经突触牢固绑定，秒级还原"]
```

### 2.3 图像生成质量的三级演进与质感飞跃

在生成助记卡片插画时，作者经历了三次关键的技术迭代：

| 迭代阶段 | 生成方式与表现 | 遇到的问题与破局方案 |
| :--- | :--- | :--- |
| **阶段 1：普通生图** | 使用常见免费文生图模型 | • **问题**：生成的图片往往自带牛皮纸底色、多余的白色卡片边框、甚至胡乱拼凑的英文字母，风格杂乱如拼贴画 |
| **阶段 2：提示词强约束** | 优化 Negative Prompt 与风格词 | • **方案**：严格加入负向约束 `--no text, no ui, no frame, no borders`，强制输出“纯净视觉主体”，去除所有多余边框 |
| **阶段 3：接入阿里生图 API** | 采用阿里云图像生成接口（通义万相）批量生产 | • **质感飞跃**：将阿里云官方 API 开发文档直接喂给 Codex，让 Codex 编写 Python 批量调用脚本，自动轮询下载并归档，画风高度统一，直接达到商用级插画标准 |

```python
# Codex 编写的阿里云批量生图与转存脚本示例（核心骨架）
import requests
import json
import time

API_KEY = "your_dashscope_api_key"
API_URL = "https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "X-DashScope-Async": "enable",
    "Content-Type": "application/json"
}

def generate_vocab_image(prompt):
    payload = {
        "model": "wanx-v1",
        "input": {
            "prompt": prompt
        },
        "parameters": {
            "style": "<3d cartoon>",
            "size": "1024*1024",
            "n": 1
        }
    }
    response = requests.post(API_URL, headers=headers, json=payload)
    task_id = response.json()["output"]["task_id"]
    return task_id
```

### 2.4 音频接口选型与生产性能优化

发音是语言类产品的核心体验。作者在音频链路上的踩坑与演进：

1. **初期尝试（TTS 批量合成）**：
   - 尝试使用 Edge-TTS 批量生成 MP3 音频文件；
   - **痛点**：数百个音频文件的命名、存储管理、上传极繁琐，容易产生音画不同步；
2. **中期轻量替代（网易有道公开接口）**：
   - 直接调用有道公开语音 API，无需任何本地音频文件管理：
     - 美音接口：`https://dict.youdao.com/dictvoice?audio={word}&type=2`
     - 英音接口：`https://dict.youdao.com/dictvoice?audio={word}&type=1`
   - 小程序中直接通过 `wx.createInnerAudioContext()` 播放在线 URL，极度轻便；
3. **长期生产架构演进（COS 预拉取 + CDN 缓存）**：
   - 有道公开接口存在被防盗链、频次限制与网络抖动的潜在风险；
   - 进阶生产架构：利用脚本将音频预先拉取，统一存放在腾讯云 COS 对象存储，并通过 CDN 域名做长效静态资源缓存，保证真机点读发音零延迟。

## 四、核心启发与复盘思考

1. **需求判断大于代码能力**：
   以前独立开发最大的阻碍是“做不出来”；现在最大的阻碍是“想不清楚要做什么”。AI 把制作成本压缩到极致后，真正考验的是你对具体学习场景、用户心理的敏锐洞察。
2. **垂直定制服务的降维打击**：
   例如作者为健身房开发的私教预约工具，此前店家每年要向第三方服务商支付 5000+ 元年费。用微信云开发一天做出来的定制小程序，每月云服务费仅 19.9 元，且体验更加干净轻量。这为自由开发者开拓非标垂直企业服务提供了巨大的利润空间。
