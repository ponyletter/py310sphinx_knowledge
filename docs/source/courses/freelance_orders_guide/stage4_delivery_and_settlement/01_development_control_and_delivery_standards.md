# 受控开发管控与带锁安全交付规范

软件外包交付的本质是**“用技术成果换取劳动报酬”**。在拿到全额货款或平台确认收货前，源代码是开发者手中唯一具有强制约束力的筹码。一旦过早、无防备地交出源码，开发者将立刻丧失所有议价权，极易陷入漫长无休止的被动拖欠。

---

## 1. 过程开发受控管理与进度同步 SOP

外包项目最怕“静默开发两周，交付当天大暴雷”。非技术客户在等待期间极易产生严重的焦虑与不信任感。

```{important}
**每日进度同步标准化模板：**
建议每天下班前或工作结束时，在项目对接三方群内发送标准简报：

> **【项目每日进展通报】**
> * **项目名称**：XXX 小程序开发
> * **今日完成**：
>   1. 完成用户授权登录与微信支付统一下单接口联调；
>   2. 完成商品详情页轮播图与 SKU 动态价格计算组件；
> * **明日计划**：接入后台订单管理与发货状态自动推送；
> * **需要甲方协助事项**：请张总明天中午前提供一下微信公众平台的原始 ID 和商户号证书文件。
> * **当前风险预警**：无，整体工期处于正常可控轨道中。
```

### 30 分钟技术阻塞升级预警原则
* 在开发过程中，若遭遇未曾预料的第三方接口故障、权限卡点或冷门系统 Bug，排查超过 **30 分钟** 仍无明确解决思路时，**必须第一时间在群内客观说明情况**；
* 严禁闷头硬抗数天直到交付截止日才告知客户“做不出来”。提前预警可以让客户调整预期，或由平台项目经理介入协调技术援助。

## 2. 验收演示三大“带锁交付”硬隔离方案

在客户未在平台点击“确认收货”、未结清尾款之前，**绝对严禁直接交付任何源代码文件、Docker 镜像包或生产环境服务器 Root 密码！**

```{mermaid}
flowchart TD
    DevDone["本地功能开发完毕"] --> Choice{"选择哪种安全验收方案？"}
    Choice --> Opt1["方案 A：自建测试服务器演示 (首选)<br/>部署在开发者自己的 VPS, 仅提供访问网址"]
    Choice --> Opt2["方案 B：全流程超清录屏演示<br/>OBS 录制端到端功能闭环, 留存操作证据"]
    Choice --> Opt3["方案 C：远程屏幕共享受控体验<br/>腾讯会议/ToDesk 连线演示, 核心代码不出机"]
    
    Opt1 --> ClientTest["客户在线操作测试验证"]
    Opt2 --> ClientTest
    Opt3 --> ClientTest
    
    ClientTest --> BugFix["根据反馈修改清单内 Bug"]
    BugFix --> ConfirmPay["客户在平台点击确认收货 / 付清尾款"]
    ConfirmPay --> FinalDelivery["正式移交全套源码与部署文档"]
```

### 方案 A：自建测试服务器域名演示（推荐最优解）
* 将系统部署在开发者自己的云主机上，绑定二级临时测试域名；
* 数据库填充模拟脱敏测试数据，前端开放测试账号供客户与其团队任意登录试用；
* **安全特性**：服务器在开发者手中，客户只能通过浏览器或小程序体验功能，无法触碰到任何后端源码与核心算法。

### 方案 B：超清端到端录屏交付（针对单点功能/脚本）
* 针对数据采集脚本、算法模型或单点接口对接，使用 OBS Studio 录制一段 3~5 分钟的一镜到底超清视频；
* 完整演示从“启动程序 $\to$ 传入参数 $\to$ 控制台输出 $\to$ 目标数据成功入库/报表生成”的全流程；
* 录屏具有极高的取证法律效力，能够证明在交付节点程序功能是 100% 完好运行的，防止客户后续因自身环境配置错误而恶意投诉代码不能跑。

### 方案 C：远程连线受控体验
* 针对强依赖客户本地私有硬件（如串口刷卡机、本地工控设备）的特殊项目，通过腾讯会议共享屏幕或向日葵受控模式，在监督下由客户操作测试，代码文件始终保留在开发者开发机中。

## 3. 标准交付物包（Standard Delivery Package）规范

当且仅当客户在平台完成**“确认收货”**或尾款已安全到账后，开发者向客户交付正规交付物压缩包，包内包含：

```text
Project_Delivery_Package/
├── 01_Source_Code/              # 规范源代码 (排除 node_modules, .git, 临时构建产物)
│   ├── backend/
│   └── frontend/
├── 02_Database/                 # 数据库初始化结构与种子数据
│   ├── init_schema.sql
│   └── default_data.sql
├── 03_Documentation/            # 详尽文档手册
│   ├── 系统架构设计说明.pdf
│   ├── API 接口文档.html
│   └── 生产环境快速部署运维手册.md   # 包含环境依赖版本、启动命令、Nginx配置示例
└── 04_Verification/             # 验收证据备忘
    └── 客户确认验收签字回执.png
```

```{tip}
**部署协助边界**：
标准报价通常仅包含**“提供详尽部署文档 + 赠送 1 次免费远程协助部署（限时 2 小时内）”**。若客户频繁更换服务器、要求多套复杂集群配置或因其服务器配置过低无法运行，超额技术支持必须按工时另行计费。
```
