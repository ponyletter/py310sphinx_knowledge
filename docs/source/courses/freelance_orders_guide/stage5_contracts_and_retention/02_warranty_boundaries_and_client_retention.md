# 售后运维边界划定与老客户鱼塘复利

技术外包常言道：**“做成一单赚点小钱，留住一个老客户赚几年复利”**。很多新手容易陷入两个极端：要么在项目交付后对客户不管不问甚至直接拉黑，导致口碑败坏；要么缺乏边界意识，项目上线半年后客户随便一个新增需求都免费加班死磕，沦为廉价保姆。建立严谨的售后运维边界与长效鱼塘运营，是实现收入跃迁的分水岭。

---

## 1. 售后服务边界标准（免费 vs 收费分水岭）

项目交付验收并全额结款后，双方正式进入维保（Warranty）阶段。在合同或交付备忘录中必须划清黑白分明的界限：

```{mermaid}
graph TD
    Request["客户提出售后服务请求"] --> Check{"该请求是否属于原 PRD 范围内的系统 Bug？"}
    
    Check -- "是 (如代码报错/支付偶发异常)" --> TimeCheck{"是否处于约定的免费质保期内？<br/>(小单通常1个月, 中大单1~3个月)"}
    TimeCheck -- "在质保期内" --> FreeFix["✅ 免费限时响应修复 (48小时内处理完毕)"]
    TimeCheck -- "已超出质保期" --> ChargeA["💰 收费按次/按工时检修<br/>(或推荐升级签订年度维保合同)"]
    
    Check -- "否 (新增功能 / UI大改 / 换服务器)" --> ScopeCheck["判定为增量变更 (Change Request)"]
    ScopeCheck --> ChargeB["💰 重新评估工期并出具二期报价单<br/>(严禁无底线免费赠送)"]
```

### 维保边界对照表

| 维保性质 | 具体事项范畴 | 服务承诺与计费标准 |
| :--- | :--- | :--- |
| **免费售后服务** | 1. 交付验收后发现的原功能逻辑 Bug 或页面显示异常；<br/>2. 首次上线生产环境的配置参数调优；<br/>3. 因代码自身引发的数据库报错或接口超时。 | 质保期内（通常约定 **1 ~ 3 个月**）免费修复，常规 Bug 48 小时内响应闭环。 |
| **有偿增值服务 (需额外付费)** | 1. 客户业务调整提出的**新增页面、新增业务字段或新流程**；<br/>2. 甲方自行迁移更换云服务器主机或域名重新绑定配置；<br/>3. 微信/支付宝/高德等第三方平台接口协议重大升级导致的代码被动重构；<br/>4. 人工批量录入清洗历史业务数据、设计制图美化素材。 | 单独评估工时与难度，按 **100~200 元/h** 或单次任务包签约收费。 |

## 2. 统一售后群的高情商闭环解散规范

很多派单对接群在项目交付完毕后长期闲置，客户几个月后突然在群里艾特开发者要求免费改东西，极易滋生尴尬矛盾。标准的外包团队在质保期满时，会执行优雅的**“正式闭环交接”**：

> **开发者质保期满交接话术范本**：
> “@张总 您好！截止到今天，我们双方约定的本项目系统免费质保期（30天）已圆满结束。过去一个月内系统运行平稳，所有既定功能均已稳定交付上线。
> 根据平台外包规范，本项目交付群将在今天下午 18:00 正式关闭归档。后续如果您有新的二期业务升级、系统新增功能或希望签订《年度技术维保协议》，欢迎随时通过企业微信与我们联系。非常荣幸能与您团队合作，祝贵司业务蒸蒸日上！”

## 3. 老客户深度复利：构建自由职业者的私域“提款机”

在自由职业领域，**获取一个全新陌生客户的成本，是维护一个老客户成本的 5 倍以上**。一线成熟独立开发者的业务来源中，**50% ~ 70% 的高利润订单来自老客户的二期续约与口碑转介**。

### 1. 建立长效老客户信任飞轮
* **交付即建档**：每一个服务过的客户，在个人 CRM 或 Notion 中记录其公司业务背景、所用技术栈、服务器到期时间与决策人性格特点。
* **定期主动问候与技术巡检**：在重大节假日或大促节点（如 618、双11、元旦前夕），主动向老客户发送一条问候并附带免费小福利：“张总，快到年底大促了，抽空帮您远程免费检查了一下服务器磁盘空间和数据库备份日志，目前一切正常，祝大卖！”
* **超预期的温度感**：客户会深深记住这位负责、靠谱的技术专家，未来一旦有任何软件需求或朋友打听做系统，**你是他脑海中浮现的唯一候选人**。

### 2. 从“零散接单”向“年度技术顾问与产品资产”跃迁
* **转型模式 A：年度常年技术维保（SLA 模式）**：
  * 面向缺乏全职 IT 人员的中小企业客户，推荐按年购买技术管家服务（如收取原项目合同金额的 **15% ~ 20%/年**，提供每月定期巡检、数据冷备份与优先 Bug 响应），轻松锁定数万元的被动年费收入。
* **转型模式 B：行业通用方案产品化（超级个体终极目标）**：
  * 在接了 3~5 个类似行业（如外卖跑腿、同城家政、二手交易）的项目后，将共性底层代码抽象封装为自研的开源系统或微型 SaaS 模板；
  * 配合短视频公域内容营销，将一套软件以源码授权形式以几千元价格卖给全国数百个客户，彻底完成**“从出卖时间到售卖资产”**的自由职业跃迁！
