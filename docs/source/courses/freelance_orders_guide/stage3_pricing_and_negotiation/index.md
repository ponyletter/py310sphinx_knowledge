# 第3阶段 商业博弈：科学报价模型与价格谈判策略

本阶段深入剖析技术外包中的**定价逻辑、成本核算公式与商务博弈技巧**。很多程序员技术扎实，却因“不会核算真实成本、不敢开价、随意降价、被客户轻易套路”而沦为廉价劳动力。通过本阶段学习，你将建立起理性的科学报价模型，掌握价格谈判的主导权。
