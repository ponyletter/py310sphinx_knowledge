# 技术外包与自由职业接单实战指南

本课程是专为**程序员、设计师、独立开发者与超级个体**量身打造的技术副业兼职、商业外包与自由职业全流程实战手册。

课程系统整合了一线技术派单平台、资深外包团队、一线闲鱼电商操盘手及法务财税专家的真实商业操盘经验，从底层认知、接单渠道、闲鱼精准起号出单、需求与工具、商业博弈、工程履约、个人工作室创办到一线真实商战案例，带你构建不可替代的技术商业闭环。

---

## 📑 阶段架构概览与核心能力对照

| 阶段划分 | 核心定位 | 解决痛点 | 交付成果与能力跃迁 |
| :--- | :--- | :--- | :--- |
| **[第1阶段 规范准入与全网渠道获客](stage1_rules_and_channels/index)** | 商业合规与全域拓客 | 盲目接黑灰产单遭罚没、找不到客户来源、不懂客单价梯度 | 筑牢接单四大铁律与合规底线，掌握闲鱼、威客、QQ/微信派单群等全网渠道布局 |
| **[第2阶段 闲鱼矩阵：低门槛精准快速出单](stage2_xianyu_traffic_and_orders/index)** | 低成本精准商业获客 | 零基础不会起号、发布商品无浏览无曝光、遭遇同行恶意白嫖 | 玩透闲鱼电商流量机制，掌握【我要搞副业】多类目发布与技能认证，熟练运用“超级擦亮”地域付费投流，进入官方钉钉扶持生态 |
| **[第3阶段 效能沟通：工程工具与需求边界锁定](stage3_tools_and_requirements/index)** | 研发提效与需求防蔓延 | 远程调试卡顿、需求模糊反复膨胀、做完客户不认账 | 熟练运用 Cursor AI / Reqable 提效工具栈，输出不可变更的 PRD 功能清单 |
| **[第4阶段 商业博弈：科学报价与谈判攻防](stage4_pricing_and_negotiation/index)** | 利润把控与价格攻防 | 报价过高丢单、报价过低亏本内卷、被客户肆意砍价 | 掌握四要素报价核算公式与市场行情基准，熟练运用“降价必砍需求”与拒绝免费 Demo 战术 |
| **[第5阶段 工程履约：受控开发、安全验收与财税结算](stage5_delivery_and_settlement/index)** | 交付风控与资金安全 | 客户不付尾款卷走源码、嵌入式软硬件踩坑、发票税负算不清 | 建立“测试服务器托管 + 录屏交付”安全硬门禁，掌握定金防线、发票税点与退单调解机制 |
| **[第6阶段 规模进阶：个人工作室办证与中介派单运营](stage6_studio_and_agency_scale/index)** | 商业正规化与团队杠杆 | 无法承接企业对公大单、无票寸步难行、个人时间精力见顶 | 掌握个体工商户注册、公章刻制、税务报道全流程，跑通中介派单吃服务差价与团队协同 |
| **[第7阶段 实战复盘：一线商战博弈与血泪避坑集锦](stage7_real_world_cases_and_qa/index)** | 实战脱敏与认知跃迁 | 遭遇大单烂尾谈崩、被专业销售套路拿捏、深陷工科直男思维 | 深度剖析 8k 大单谈崩根因与真实纠纷调解，克服程序员思维缺陷，掌握合同法务终极维权 |
