# 05. 简答题 (Answer Short Question, ASQ) 极速通关指南 —— A 级听力送分题

:::{admonition} 题型核心参数一览 (At a Glance)
:class: tip
| 核心指标 | 官方标准参数 |
|---|---|
| **考场题量** | 5–6 题 |
| **供分单项** | **仅听力 (Listening)** *(2025 年 8 月改版重大调整：不再向口语供分)* |
| **音频输入** | 3–9 秒简短常识提问，仅播放 1 次 |
| **准备时长** | **0 秒**（音频播完即刻开麦） |
| **答题时长** | 10 秒录音窗口 |
| **官方计分规则** | **对/错 二元计分 (Binary)**：词语选择恰当得 1 分，错误得 0 分。无发音流利度细分。 |
:::

---

## 为什么 ASQ 是 A 级必拿的 5–6 个白送基础分？

这是整场考试在操作层面最简单、最轻松的一道题目。
系统为你朗读一句简短的事实性常识提问，你只需要用**一个英文单词或极短的名词短语**脱口而出回答即可。它**完全不单独考核发音和流利度特质**，只考核 Content（词选对了给 1 分，选错给 0 分）。

考查的知识全部为**中小学水平的常识与生活高频词汇**，绝非高深莫测的学术生僻概念。

:::{important} 决胜本题的两大黄金实战铁律
1. **只回答 1 到 2 个单词！绝对不要说完整长句！**
   回答 "A triangle" 与回答 "The geometric shape you are asking about is a triangle" 拿到的分数**完全一模一样**！说长句不仅耗费宝贵的 10 秒时间，还徒增语法和口误的风险。
2. **每次都必须脱口而出！绝不沉默弃权！**
   猜错也是 0 分，沉默也是 0 分。猜一个答案完全免费，一旦蒙对就是实打实的听力净胜分！
:::

:::{warning} 警惕 3 秒静音麦克风强行截断规则
培生官方题型说明明确指出：**在 ASQ 题目中，开麦后若超过 3 秒没有有效声音输入，麦克风将强行关闭并直接跳入下一题！** 
听到录音结束提示音后，务必立刻报出单词。哪怕大脑还在思考，想到什么相近的词立刻说出来，绝不能在死寂中犹豫超过 3 秒。
:::

## 极速应答实战技巧 (Technique)

1. **听清疑问引导词**：
   - *What*（问物体/概念）➔ 答名词；
   - *Where*（问地点）➔ 答场所；
   - *Who*（问人物身份）➔ 答职业/角色；
   - *Which / Is it A or B*（二选一）➔ 直接报出其中一个选项；
   - *How many*（问数量）➔ 直接报出具体数字。
2. **回答时冠词可有可无**：说 "A vet" 或单纯说 "Vet" 均完全有效给分，千万不要为了纠结用 a 还是 the 而中途卡壳。
3. **如果想到两个近义词，果断二选一**：千万不要犹豫说出 "A chemist, or maybe a pharmacy"，这种游移不定的表达容易干扰识别，果断大声说出一个即可。
4. **完全不知道答案时的保命蒙题法**：如果问你一种你完全没听过的“instrument（仪器）”，立刻大声回答 "Thermometer" 或 "Microscope"！蒙对了就是赚到，蒙错了没有任何惩罚。

## 极简复习计划：每天只需 5 分钟

ASQ 不需要也不值得投入几周时间专项死磕。最高效的复习法是：
- 考前连续 3–5 天，每天花 5 分钟通读一遍上述高频常识中英对照清单；
- 遮住英文答案，进行口头快速抢答，要求自己 2 秒内脱口而出；
- 熟练掌握后即可收工，将宝贵的时间投入到 S 级的 WFD 和 RS 上！
