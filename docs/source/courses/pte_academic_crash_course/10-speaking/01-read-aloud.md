# 01. 朗读文本 (Read Aloud, RA) 极速通关指南 —— S 级战略核心

:::{admonition} 题型核心参数一览 (At a Glance)
:class: tip
| 核心指标 | 官方标准参数 |
|---|---|
| **考场题量** | 6–7 题 |
| **供分单项** | **仅口语 (Speaking)** *(2025 年 8 月改版重大调整：不再向阅读分供分)* |
| **输入形式** | 最多 60 词的学术短文，清晰完整呈现在屏幕正中央 |
| **准备时长** | 30–40 秒倒计时（麦克风关闭状态） |
| **答题时长** | 根据文本长度浮动（通常给 30–40 秒录音时间） |
| **官方考查特质** | Content (内容), Pronunciation (发音 0–5分), Oral Fluency (流利度 0–5分) |
:::

:::{warning} 必须立即纠正的网络过时误导
国内大量旧攻略宣称：“Read Aloud 是拯救阅读单项的半边天”。**这在 2025 年 8 月前是事实，但现在彻底失效了！** 培生最新版官方评分指南已将 Read Aloud 的供分属性明确变更为**仅供口语**。
即便如此，Read Aloud 依然高居 **S 级战略核心**，原因见下文。
:::

## 为什么 RA 依然是 S 级战略核心？

**因为文本直接印在你的眼前。** 
这里没有听力辨音压力，没有现场记忆负担，不需要你构思观点，也不需要组织语法。这是全场最纯粹的**声音交付任务 (Pure Delivery Task)**。

更重要的是：**Read Aloud 是你建立全场口语发音与流利度习惯的“母题黄埔军校”**。你在 RA 中练就的稳定语速、意群断句、重音节奏和“绝不倒车自我纠错”的肌肉记忆，将直接原封不动地赋能给后续的 Repeat Sentence、Describe Image、Retell Lecture、SGD 和 RTS。**练好 RA 的流利度，就等于直接拉升了整场口语的基本盘！**

---

## Content（内容度）特质评分准则

在 Read Aloud 中，Content 的评分规则极其机械：
> *"每个单词的替换 (replacement)、漏读 (omission) 或擅自添加 (insertion)，均记为一次错误。满分取决于题目文本的总词数。"*

**实战铁律**：按屏幕上的文字顺序逐词读完，不添字、不漏字、不错读。

## 两阶段高效实战法 (The Two-Phase Method)

![RA 与 RS 口语流程对照：朗读与复述答题关键步骤](../images/whiteboard/04-ra-rs-speaking.png)

### 第一阶段：30–40 秒准备窗口黄金利用法则

绝大多数考生在这个窗口期只是双眼发呆看一遍文本，白白浪费了全场最宝贵的准备资源。请严格按照以下三步执行：

#### 1. 意群切分，脑中画斜杠（前 10 秒）
快速扫读句子，找出逗号、从句引导词、介词短语前以及长主语与谓语之间的天然呼吸气口，在大脑中精准插入停顿线（`/`）：

> "Urban planners / have long recognised / that green spaces / improve public health, / but the economic case / for preserving them / has only recently / been quantified."

**为什么必须意群切分？** 官方流利度特质明确考核“节奏、意群组织与重音（rhythm, phrasing and stress）”。如果每个词发音完全等长、像机器人一样蹦字，哪怕每个音标都标准，流利度也会被算法判定为极低档！

#### 2. 排查发音地雷（中间 15 秒）
用目光快速检索三类“卡壳地雷”：
- **生词与长难词**：提前确定一个大胆读音。**自信但读错音仅损失微小的发音小数点；如果中途停下来死抠发音，整题流利度将直接暴跌**！
- **数字、年代与百分比**：提前在心中念出完整读音：
  - `1,250` ➔ "one thousand two hundred and fifty"
  - `1890s` ➔ "the eighteen-nineties"
  - `3.4%` ➔ "three point four percent"
- **专有名词与人名地名**：无论发音是否地道，保持平稳读过，算法绝不会比对地名专有名词词典。

#### 3. 无声唇动对口型预演（最后 10 秒）
嘴唇微动、不出声音地对口型试读首句，校准自己的节拍器语速。

:::{danger} 严禁在准备时间内出声朗读！
考场规则明确禁止在未开麦阶段发出干扰周围考生的声响。部分严格考点的考务人员会提出警告。请保持绝对无声的唇部运动。
:::

---

### 第二阶段：正式录音交付（Delivery）

1. **听到提示音后 1 秒内果断开口**：系统开麦后若超过 3 秒检测不到有效声学信号，麦克风将强行关闭并直接跳题！
2. **设定比日常说话稍慢但极其匀速的语速**：从第一个词到最后一个词，始终如一。不要在简单的句子上飙车，也不要在难词上减速。
3. **只在切分好的斜杠处做半秒自然微停顿**：意群内部词与词之间严禁出现气口停滞。
4. **绝不回头倒车纠错 (Never self-correct)**：读错一个词，只扣 1 个 Content 步骤分；一旦倒回去重新读，全篇流利度直接崩盘。读错就当没发生，眼神紧盯后面的词继续平稳读下去。
5. **音量恒定，气贯长虹**：很多考生在读到最后半句时气息不足、音量骤降，导致机器采集到的音频信号过弱而丢分。吸足气，音量坚挺维持到最后一个词。
6. **读完立刻点击 Next**：说完最后一个词，鼠标迅速点击 Next 确认，不要对着麦克风叹气、咳嗽或发出任何无关声响。

:::{tip} 语速黄金标尺：60 个词 25–28 秒完成
优秀的 Read Aloud 语速约为 **每分钟 130–150 词 (WPM)**。
- 一段 60 词的文本，耗时在 **25–28 秒** 之间最为从容自然。
- 如果你 18 秒就读完了，说明你在胡乱赶速度，辅音被严重吃掉；
- 如果你读了 40 秒还没读完，说明你拖沓卡顿，流利度得分会很低。
在日常练习时，务必用手机秒表掐表校准这种节奏感。
:::

## 真正拉开发音分的五大底层细节 (Pronunciation Levers)

机器算法不看重你的英音或美音腔调。官方最高档描述明确写道：“*以常人易于理解的方式发音，极个别的辅音、元音或重音轻微偏差不影响整体理解*”。你真正要解决的是以下五大系统性发音硬伤：

### 1. 学术词汇的单词重音位置 (Word Stress)
英语是重音计时语言，重音位置一旦放错，算法将完全无法在语音库中匹配该词。高频易错词清单：

| 词汇 | 正确重音位置 | 常见错误发音 |
|---|---|---|
| **development** | de-**VEL**-op-ment | **DEV**-elopment |
| **necessary** | **NEC**-essary | nec-**ESS**-ary |
| **comparable** | **COM**-parable | com-**PAR**-able |
| **photography** | pho-**TOG**-raphy | **PHO**-tography |
| **politics** / **political** | **POL**-itics / po-**LIT**-ical | — |
| **economy** / **economic** | e-**CON**-omy / eco-**NOM**-ic | — |
| **preference** | **PREF**-erence | pre-**FER**-ence |

:::{note} 名词与动词的重音转移规律
许多由相同字母组成的双音节词汇，作为**名词时重音在前**，作为**动词时重音在后**：
- 名词：an **IN**crease / a **REC**ord / a **CON**tract / the **PRES**ent
- 动词：to in**CREASE** / to re**CORD** / to con**TRACT** / to pre**SENT**
RA 文本中大量充斥此类词汇，请务必根据其在句中的语法成分准确重读。
:::

### 2. 动词过去式 -ed 结尾的三种发音规则
很多考生遇到 -ed 统一念成 /ɪd/，这是严重的系统性发音错误：

| -ed 前置音素类型 | -ed 的真实发音 | 经典实例 |
|---|---|---|
| 前接 /t/ 或 /d/ 音 | 读 **/ɪd/**（增加一个音节） | wan**ted**, nee**ded**, predic**ted** |
| 前接清辅音 (p, k, f, s, ʃ, tʃ) | 读 **/t/** | hel**ped**, as**ked**, publi**shed**, develo**ped** |
| 前接浊辅音或元音 | 读 **/d/** | ex**plained**, re**quired**, ob**served**, ar**gued** |

### 3. 名词复数与第三人称单数 -s 结尾规则
| 前置音素类型 | -s 的真实发音 | 经典实例 |
|---|---|---|
| s, z, ʃ, tʃ, dʒ | 读 **/ɪz/**（增加音节） | cour**ses**, chan**ges**, focu**ses** |
| 清辅音 | 读 **/s/** | studen**ts**, projec**ts**, boo**ks** |
| 浊辅音或元音 | 读 **/z/** | studi**es**, metho**ds**, clai**ms** |

### 4. 辅音连缀 (Consonant Clusters) 严禁擅自添音
中国考生在遇到连续辅音时容易在辅音中间擅自加入汉语拼音式的元音 /ə/：
- *strength* 不要读成 "suh-trength"；
- *facts* 不要读成 "fack-tuh-suh"；
- *texts, asked, months, scripts, statistics* 等词汇，必须通过慢速慢读建立清晰的辅音气流控制。专项训练参见：{doc}`../60-toolkit/03-pronunciation-drills`。

### 5. 句子级重音：实词重读与虚词弱读 (Content vs Function Words)
- **实词（承载核心意义）重读**：名词、实义动词、形容词、副词；
- **虚词（语法衔接）弱读滑过**：冠词 (a, the)、介词 (of, at, in)、连词 (and, but)、代词、助动词。

> *"The re**SEARCH** was con**DUC**ted at the uni**VER**sity over a **PER**iod of **THREE** **YEARS**."*

加粗大写部分饱满重读，其余小写虚词轻盈带过。这种起伏的意群波浪感，正是机器判定你具备 4–5 分高阶流利度的声学指纹！

## 每日 15 分钟专项强化训练课表

| 备考阶段 | 建议天数 | 每日核心训练任务 |
|---|---|---|
| **第一阶段：意群切分训练** | 第 1–3 天 | 每天精选 5 篇 {doc}`../50-practice/03-read-aloud-bank` 的官方母题，**先拿铅笔划出停顿斜杠**，再掐表朗读，确保 25–28 秒内平稳读完。 |
| **第二阶段：影子跟读模仿 (Shadowing)** | 第 4–8 天 | 每天选取 1 段标准学术新闻或讲座录音，戴耳机播放，**延迟半秒同步跟读**，完全复制原声的语调起伏与重音节奏。这是见效最快的流利度神器。 |
| **第三阶段：录音质检与复盘** | 第 9–12 天 | 每天录音 5 篇自己的 RA，回放复听：数一数自己有没有倒车纠错、停顿是否突兀、句尾是否声音发飘。每天专项消灭一个坏毛病。 |
| **第四阶段：冷读盲测实战** | 第 13–14 天 | 完全不给额外准备时间，严格倒计时 35 秒准备，一次性录音通过，模拟考场极限高压状态。 |

## 新手必须立即制止的七大低级错误

| 致命失分误区 | 产生后果 | 正确纠偏操作 |
|---|---|---|
| 准备时间发呆不划断句 | 临场盲读 ➔ 蹦字断续 ➔ 流利度崩盘 | 准备期前 10 秒强制切分意群划斜杠 |
| 读错单词倒回去重新读 | 1 个词的轻微发音扣分演变成整题流利度清零 | 错就错了，坚决不回头，保持匀速向前读 |
| 盲目飙车以为语速越快越好 | 辅音吞没、含混不清，算法完全无法识读 | 稳定在 130–150 WPM，60 词用时 25–28 秒 |
| 每个单词用力均等、机械读字 | 语调扁平生硬，严重扣除意群节奏分 | 实词饱满重读，虚词自然弱读带过 |
| 遇到陌生长词瞬间卡壳停滞 | 产生长达数秒致命停顿，触发流利度惩罚 | 自信大胆读出一个发音，毫不停留平稳滑过 |
| 读到句尾声音越来越小 | 算法采集到的结尾声学波形失真削顶 | 提前换气，恒定音量支撑到句号之后 |
| 读到数字时现场计算读法 | 句中突然卡顿 3 秒 | 准备期提前把数字、年份、小数的读音在心里过一遍 |
