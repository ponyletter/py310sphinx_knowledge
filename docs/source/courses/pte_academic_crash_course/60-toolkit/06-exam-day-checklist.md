# 考前与考场当天全流程实战清单（Exam-Day Checklist）

:::{warning} 务必提前核对你所在考场的具体考务规程
不同国家、地区以及各个官方考点（Test Centre）的入场安检细则可能存在微调。**请以你收到的官方考试确认信（Booking Confirmation）及培生当前最新的考生手册（Test-Taker Handbook）为最高准则。** 本页提供的战术策略全球通用，但考务后勤细节请以准考信为准。
:::

---

## 考前最后一夜（The Night Before）

- [ ] **重温极简句式骨架：** 通读一遍 {doc}`02-template-card` 中的口语与写作骨架，复习倒扣分排雷规则。除此之外不再看任何繁杂资料。
- [ ] **回顾个人专属避坑清单：** 拿出在 {doc}`04-error-log-method` 中总结的个人错题本，牢记自己最常犯的 **5 个非受迫性失误**。
- [ ] **严禁突击学习任何新内容：** 不要再背生词，不要尝试新技巧，严禁在考前深夜做完整模考！
- [ ] **核验考试时间、考场路线与交通：** 规划好行程，确保在开考前 **至少提前 45 分钟** 抵达考场。
- [ ] **准备好符合官方要求的法定有效身份证件：** 必须是**原件、带有清晰照片、且处于有效期内**（中国大陆考场建议首选有效护照原件）。
- [ ] **核验证件信息与报名信息：** 仔细确认证件上的姓名拼音、出生日期、国籍等信息与官方报名账户**完全一致**。
- [ ] **保证充足深度睡眠：** 疲惫的大脑在考试第 2 小时后极易出现注意力涣散，而听写句子（WFD）恰恰位于全场最后 5 分钟！

## 随身携带与禁带物品清单

| 必须/允许携带的物品 | 严禁带入考位（必须存入寄存柜） |
|---|---|
| **有效的法定带照片身份证件原件**（护照） | 手机、智能手表、手环、一切电子产品 |
| 打印或电子版考试确认信（以备查验） | 个人笔记本、书籍、自备纸张或自备水笔 |
| 考场若允许，可带撕掉标签的透明瓶装饮用水 | 零食、饮料、口香糖 |
| 保暖外套（考场机房通常空调温度偏低） | 双肩包、手提包、首饰、夹克大衣等 |

:::{danger} 证件问题是唯一能在开考前瞬间取消你考试资格的致命风险！
**考场绝对不接受任何电子证件、照片截图或纸质复印件！** 任何过期证件一律视为无效。如果证件上的任何姓名拼写与报名表存在哪怕一个字母的差异，必须在考前工作日联系培生官方客服修改，绝不要等到考试当天早晨去考场现场争辩！
:::

## 考场报到与核心试音流程（At the Centre）

1. **提前 30–45 分钟到达考场：** 迟到可能会被直接取消考试资格且不退还考试费。
2. **前台安检与身份登记：** 查验身份证件、**手掌静脉扫描（Palm-vein Scan）**、现场采集数码肖像照片、电子签名。
3. **物品寄存：** 将除证件外的所有个人物品存入专用储物柜并锁好。
4. **领取草稿装备：** 在进入考位时，监考老师会发放 **塑封可擦草稿册（Noteboard booklet）与专用细头记号笔**。立即在草稿纸上试写划线，确认笔迹清晰顺畅，若不出水立即要求更换。
5. **耳机麦克风佩戴与硬件试音——【全天最关键的 30 秒】：**

:::{important} 试音回放是决定整场口语成绩最关键的 30 秒！
整场口语 28–34 道题的发音与流利度全凭 AI 语音算法模型打分。如果麦克风录入的声音波形存在问题，英语水平再高也难拿高分！

- **麦克风黄金位置：** 放置于**嘴角斜侧约一指到两指处**，绝对不要正对鼻息气流或正对嘴唇，以杜绝喷气破音。
- **发音音量：** 保持日常办公桌面对面交谈的适中、平稳音量。
- **仔细聆听耳机里的试音回放：** 试音录音完毕后，耳机中会立即播放你刚才的声音。**如果声音发虚、发闷、有严重电流杂音或伴随沉重呼吸喷麦声，立刻举手示意监考老师更换耳机或调整系统！** 绝不要带着硬件隐患勉强开考！
:::

6. **非计分个人陈述（Personal Introduction）：** 25 秒准备，30 秒录音。该项**不计入任何成绩**，纯粹用于开嗓热身，舒缓紧张情绪。

## 第一部分：口语与写作 Part 1（约 80 分钟，全程无缝无休）

### 口语通用执行铁律
- [ ] 听到提示音后 **1 秒内果断开口**，绝不迟疑；
- [ ] 中间停顿 **严禁超过 1 秒**，连续静音 3 秒麦克风将强行关闭判 0 分；
- [ ] **绝对不要自我纠错或回退重读**，读错当作没发生继续推进；
- [ ] 保持 **绝对平稳恒定的一致配速**，略慢于日常自如语速；
- [ ] 句子尾音 **保持充沛饱满音量**，不吞字、不叹气；
- [ ] 在规定时间内尽量 **完整用满作答时长**。

### 各题型抢分一句话提醒

| 题型名称 | 核心提醒与抢分红线 |
|---|---|
| **朗读文本 (RA)** ×6–7 | 用满 35–40 秒准备时间在脑海划定意群斜杠，遇到数字提早确定读法，130–150 wpm 匀速朗读。 |
| **重复句子 (RS)** ×10–12 | 听到提示音立即开口！**按顺序说对 50% 词汇即稳保 Content 2/3 分**，流利度重于完整度！ |
| **看图说画 (DI)** ×5–6 | 图表类型 → 最大值 → 最小值 → 显著走势 → 总结收尾。**所有数字前加 about/roughly**，说满 35–40 秒。 |
| **复述讲座 (RL)** ×2–3 | 抓取主题 + 3 个核心学术词 + 1 个结论。哪怕信息量不足，用听懂的词流畅说满 40 秒。 |
| **简短回答 (ASQ)** ×5–6 | **1 到 2 个单词立即秒答！** 严禁组织冗长主谓完整句，不会就果断猜一个，绝不停顿超 3 秒。 |
| **小组讨论总结 (SGD)** ×2–3 | 三列速记槽。**说满整整 2 分钟！** 展开各方论据细节与未决分歧，严禁插入个人主观评述。 |
| **情境应对 (RTS)** ×2–3 | 承认知情 → 表明立场 → 阐述原因 → **后续补救提议**。大量使用 I'm afraid/Would it be possible 等软化语。 |
| **总结文本 (SWT)** ×2 | **严格一个单句！全文只能有 1 个句号，绝不用分号！** 锁定 30–40 词，剔除一切举例细节。 |
| **大作文 (Write Essay)** ×1 | **严格 240–280 词区间，标准四段式**。用足 20 分钟，留出最后整整 2 分钟逐字检查拼写与单复数。 |

:::{tip} 调整 Part 1 漫长作战的体能节奏
口语与写作长达 80 分钟无缝连打。写作部分的 3 道题（10分 + 10分 + 20分 = 40分钟）虽然是独立计时的，但连续作战容易在大作文阶段陷入精神脱水。

**在题与题切换跳转的 3–5 秒黑屏加载空档，做一次深长呼气，调整坐姿，甩动手腕放松肌肉！**
:::

## 第二部分：阅读 Part 2（约 25 分钟，全区共用单一倒计时）

- [ ] **严格执行单题时间死线：** 完形填空 2 分钟、段落排序 2 分钟、单选 90 秒、多选 2.5 分钟。倒计时一旦触及死线，立即猜选点击 Next！
- [ ] **全场填空格彻底填满：** 两类 Fill in the Blanks 均**毫无倒扣分惩罚**，空题等于自暴自弃。
- [ ] **单选题（MCSA）务必全部作答：** 无倒扣分，排除法后快速点击。
- [ ] **段落排序（RO）必须提交一个顺序：** 基于相邻对计分，锁定确定的首对段落，其余按逻辑链顺向排好。
- [ ] **多选题（MCMA）克制防守：** 每选错一项扣 1 分！**仅勾选你在文中 100% 找到支撑的选项，绝不贪多！**
- [ ] **誓死护航末尾的拖拽填空：** 拖拽填空位于阅读区最后几道题，分值重且无倒扣分，必须预留至少 4–5 分钟从容作答！
- [ ] **切勿全文精读：** 下拉填空以空格为中心向前向后扫描；客观选择题以题干设问为导向定位关键词。

> **终场目标：** 考试倒计时归零前还剩 30–60 秒，**全场未作答空格数为 0**！

:::{note} 务必接受 10 分钟中场休息（Take the Break）！
阅读结束后，系统会弹窗提示是否需要 **10 分钟可选休息**。**毫不犹豫地点击接受！**  
走出考场机房，去洗手间洗一把脸、喝两口温水、远眺放松眼部睫状肌、做深呼吸。绝不要在休息室看资料或纠结刚才的失误。你即将面对全场权重最高、且位于末尾的绝杀题型——听写句子（WFD）！
:::

---

## 第三部分：听力 Part 3（约 35 分钟）

- [ ] **音频播放前抢先读题与选项：** 听力区最具提分杠杆的习惯。音频只放一遍，带着预判有目的地听，与盲目泛听效果完全不同！
- [ ] **总结口语（SST）：** 严格控制在 **55–65 词**（低于 40 词或超过 100 词判 0 分！），2–3 个完整句子，全部使用过去时态。
- [ ] **听力填空（L-FIB）：** 音频播放前快速扫读文本预判词性；播放时**直接在键盘上敲入完整词汇**；全填满，零负分。
- [ ] **选出正确摘要（HCS）：** 核心在于**匹配论述范围（Scope）**，千万别选充斥着生僻熟悉词但以偏概全的干扰项。
- [ ] **单选与选词（MCSA / SMW）：** 全部作答，无负分。利用文意逻辑方向进行末尾推导。
- [ ] **听力多选（L-MCMA）：** 在草稿纸上记录发言论据，仅勾选完全有明确支撑的选项，避免倒扣分。
- [ ] **突出错误单词（HIW）：** 鼠标光标跟随原声移动，**仅在音频播放期间点击**！音频播完后**严禁回溯乱点**，点错假词倒扣 1 分！
- [ ] **听写句子（WFD）×3–4 题：** 全神贯注听完原句 → 极速在草稿纸写下首字母与核心主谓词块 → 顺向还原句子 → 全面排查时态与单复数 `-s` → 放心提交。**在保证真实捕捉的基础上，若对单复数不确定可写上变体，多写单词绝不扣分！**

:::{important} 决战最后 5 分钟：WFD 题王终局防线
此时你已经高度运转近 2 个小时，身心处于极度疲劳期。**这是你前期所有刻意练习爆发威力的时刻！** 3 到 4 个句子，同时主宰听力与写作两个单项的核心命运。

不要因为看到终点线而匆忙乱点，也不要过度纠结单个介词。打出骨架、还原句子、逐词核验拼写，稳健点击 Next！
:::

## 白送分（零失误）硬性自检清单

以下每一项失分都是纯粹的操作流程失误，与真实的英语能力毫无关系。**保住这些分数是考场最廉价的提分手段：**

- [ ] 大作文词数严格处于 **240 至 280 词** 之间（绝对不在 120 词以下或 380 词以上）；
- [ ] 文本摘要（SWT）必须且只能有 **一个英文句号**，**绝无分号 `;`**，字数 30–40 词；
- [ ] 口语摘要（SST）词数处于 **55 至 65 词** 之间（绝对不在 40 词以下或 100 词以上）；
- [ ] 口语所有题型中，**无任何一处出现空白未答**；
- [ ] 口语所有题型中，**无任何一处出现超过 3 秒的停顿沉默**；
- [ ] 阅读与听力所有填空题中，**无任何一个空格遗留为空白**；
- [ ] 所有单选题 **全部作答**；
- [ ] 所有段落重排题 **全部提交了一个排列顺序**；
- [ ] 听写句子（WFD）中捕捉到的所有单词 **全部完整输入**；
- [ ] 多选题（MCMA）与挑错词（HIW）严格做到 **仅勾选 100% 确定项，克制贪心**。

## 考后成绩单查收与复盘再战准备

- **成绩单送达时间：** 通常在考试结束后的 **48 小时内**，成绩会自动同步至你的 Pearson 官方账户并发送邮件通知。
- **看成绩单前先盲写考场复盘：** 在查分前，凭记忆写下自己在考场感觉最不稳的题型与失误点。随后将真实成绩单与你的自评进行对照，这能极其精准地校准你的自我认知，为可能的二战复习指明方向。
- **关于二战准备与安全垫心理：**  
  PTE 转考与预约考位极其灵活。若成绩距离目标线相差在 3 分以内，结合 IRT 模型的测量误差规律（详见 {doc}`../00-foundations/03-how-scoring-works`），请在目标分之上**预留 4–5 分的安全容错垫**，对照瓶颈定位表迅速修复短板，预约 1–2 周后的考位即可稳稳通关！

## 考前 1 分钟救命十大法则（极简通关口诀）

如果进考场前你只有 1 分钟快速扫一眼，请牢记这 10 句话：

1. **哔声一响一秒内开口，全场绝不沉默。** 沉默直接归零。
2. **读错说错绝不纠错，舌头打滑直接向前冲。**
3. **口语所有题目尽量撑满规定时间槽。**
4. **基于眼前的真实材料描述，严禁背诵万能假大空段落。**
5. **大作文 240–280 词，SWT 唯一单句 30–40 词，SST 55–65 词。**
6. **填空必须全填满，单选全猜满，排序全排好。零扣分，白送分绝不放过。**
7. **多选与挑错词：只有 100% 确定才点。全场只有这三处倒扣分。**
8. **听力音频播放前，先读题干与选项。**
9. **卡死阅读时间死线，拼死保护末尾的拖拽填空。**
10. **WFD 是全场终极绝杀，写下你能想到的每一个词，多写不扣分。**
