# 短期分级备考课表规划（Study Plans）—— 7 天 / 14 天 / 21 天科学冲刺方案

根据你距正式考试的实际可用时间，本章提供三套不同梯度的备战时间表。所有课表均严格遵循 {doc}`../00-foundations/04-priority-triage` 的核心优先级法则：**Tier S 绝命核心题倾斜最多精力，Tier C 极低性价比题仅做极简防守**。

:::{admonition} 三套课表必须共同遵守的铁律
:class: important
**每一次学习任务开始的前 10 分钟，必须雷打不动地用于错题本复盘**（详见 {doc}`04-error-log-method`），之后才能开启新题目的练习！这是确保你的备考在“实质性消灭错误”而非“把坏习惯练熟”的唯一机制。
:::

---

## 方案 A：7 天极限冲刺课表（真正的高强度集训）

- **适用对象：** 距离考试仅剩 1 周，迫切需要稳定通过基准分数线（如总分 50–65 分区间）的考生。
- **时间投入：** 每天约 3 小时连续高效专注。

:::{warning} 7 天冲刺中你必须战略性“断舍离”的内容
在这 7 天中，**严禁在复述讲座（RL）、小组讨论总结（SGD）、突出错误单词（HIW）或阅读多选题（MCMA）上消耗大块时间**！你只需花 15 分钟通读其单页解题战术与防守规则即可。

这些是全场最难啃、分值产出最低的题目；你的每一分钟都必须全力注入产出极高的 **Tier S 核心题库**！
:::

### 第 1 天：考试规则认知与全科摸底诊断（3 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **60 分钟** | 通读 Stage 0 全部五篇基础指南（{doc}`../00-foundations/01-what-the-test-is` 至 {doc}`../00-foundations/05-glossary-and-banks`）。**绝对不要跳过**，战略清晰是 7 天逆袭的前提。 |
| **20 分钟** | 通读 {doc}`02-template-card`，特别铭记 2025 人工双评 Content 闸门红线，建立语法骨架意识。 |
| **40 分钟** | **全科诊断摸底：** 连续完成 10 句 WFD（Set A）、10 句 RS（Set A）、3 篇 Read Aloud 短文朗读、1 道阅读 FIB。全程录音并计分。 |
| **40 分钟** | 建立错题本与拼写子本（{doc}`04-error-log-method`）。将摸底测试的所有错误按五大原因完成归类。 |
| **20 分钟** | 通读 {doc}`03-pronunciation-drills`，完成一次 10 分钟影子跟读（Shadowing）训练。 |

> **第 1 天结束自检：** 必须明确指出你最薄弱的交叉单项、听到哔声后的开麦延迟（秒数）以及生词拼写失误率。

---

### 第 2 天：绝杀双核——听写句子 (WFD) + 重复句子 (RS)（3 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **10 分钟** | 错题本复盘（首测昨日拼写生词） |
| **50 分钟** | 研读 {doc}`../40-listening/01-write-from-dictation` 解题法 + 实操 15 句 WFD（Set A/B）。采用“先记首字母主干、再顺向还原”法。 |
| **15 分钟** | 拼写专项训练：将今日所有写错的学术单词每个动笔抄写 5 遍。 |
| **50 分钟** | 研读 {doc}`../10-speaking/02-repeat-sentence` 解题法 + 实战 20 句 RS（Set A）。**唯一核心指标：听到提示音 1 秒内开口，中间绝对零卡顿！** |
| **30 分钟** | 朗读文本（RA）：练习 5 篇学术短文，在文本上标注意群停顿斜杠并录音。 |
| **15 分钟** | 影子跟读训练（Shadowing）。 |
| **10 分钟** | 通读 {doc}`../10-speaking/05-answer-short-question`，快速浏览 40 个常识问答题。 |

---

### 第 3 天：阅读完形填空 + 写作逻辑底座（3 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **10 分钟** | 错题本复盘 |
| **45 分钟** | 研读 {doc}`../30-reading/01-fill-in-the-blanks` 破题漏斗 + 熟记核心固定搭配与介词表。 |
| **45 分钟** | 深度推导演练 {doc}`../50-practice/06-reading-practice-set` 第 1–3 题，逐空梳理逻辑与词性。 |
| **40 分钟** | 研读 {doc}`../20-writing/02-write-essay` 骨架。**仅进行审题提纲演练**：挑选 5 道大作文母题，每题限时 2 分钟列出 6 个核心论据词块，暂不写全文。 |
| **25 分钟** | WFD 强化：12 句（Set B）。 |
| **15 分钟** | RS 强化：15 句（Set B）。 |
| **15 分钟** | 影子跟读 + 3 篇 RA 录音。 |

---

### 第 4 天：口语大容量输出——看图说画 (DI) + 情境应对 (RTS)（3 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **10 分钟** | 错题本复盘 |
| **50 分钟** | 研读 {doc}`../10-speaking/03-describe-image` 五步法。对网上或题库中的 20 张图表进行“10秒找极值”极速扫图特训。 |
| **40 分钟** | 演练 6 道 DI 全真图表（{doc}`../50-practice/04-describe-image-bank`），严格录音。**复盘核心：是否撑满了 35–40 秒？有无卡顿？** |
| **30 分钟** | 研读 {doc}`../10-speaking/07-respond-to-a-situation` + 录制 5 道情境题，每题 40 秒，强化礼貌软化句式。 |
| **30 分钟** | WFD 强化：12 句（Set B/C）。 |
| **25 分钟** | RS 强化：15 句（Set B/C）。 |
| **15 分钟** | 影子跟读训练。 |

---

### 第 5 天：写作全篇输出 + 阅读速度压迫（3 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **10 分钟** | 错题本复盘 |
| **35 分钟** | 研读 {doc}`../20-writing/01-summarize-written-text` + 练习题库中 2 篇 SWT。**严格核对：是否为唯一单句？词数是否在 30–40 词？** |
| **25 分钟** | **限时完整撰写一篇大作文（20分钟）**，随后对照官方七大特质标准逐项自我评分。 |
| **35 分钟** | 限时攻克阅读题集第 4–7 题，**严格卡死单题时间死线（每题不超过 2 分钟）**。 |
| **25 分钟** | 研读听力小题防守战术：{doc}`../40-listening/03-fill-in-the-blanks` 与 {doc}`../40-listening/05-multiple-choice-and-friends`。 |
| **30 分钟** | WFD 强化：12 句（Set C）。 |
| **20 分钟** | RS 强化：15 句（Set C）。 |

---

### 第 6 天：全真限时模考 + 漏洞大排查（3 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **135 分钟** | **全真限时模拟考试**：首选购买一套培生官方 Scored Practice Test；若无则使用第三方全真模考软件。**务必一次性不间断完成 Part 1（80分钟口语+写作），体验真实生理疲劳！** |
| **45 分钟** | **模考全面归因复盘：** 记录每一个做错的题型。统计：留空空格数、超时次数、口语中途停顿秒数、各写作任务实际字数。 |

:::{tip} 模考购买建议
如果预算只允许购买一项付费产品，务必购买官方的 **Pearson Scored Practice Test**。它是全球唯一使用真实机评引擎进行打分的模考工具；第三方模拟网站的算法打分往往偏宽松或存在失真。
:::

### 第 7 天：轻量整合与考前生理储备（2 小时）

| 时间分配 | 任务内容与具体执行 |
|---|---|
| **20 分钟** | 错题本拼写大清盘：盲写复测本周出现过的**全部拼写错词**。 |
| **30 分钟** | WFD 混合强化：精选 15 句——**刻意安排在精力疲倦时进行听写，模拟考场终局状态**。 |
| **25 分钟** | RS 强化：15 句快速反应跟读。 |
| **20 分钟** | 5 篇 RA 短文跟读 + 影子跟读热身。 |
| **15 分钟** | 再次通读 {doc}`02-template-card` 与 {doc}`06-exam-day-checklist`。 |
| **10 分钟** | 在纸上完整默写一遍**考场草稿板个性化避坑自检表**。 |

> **特别提示：** 第 7 天傍晚务必停止学习！严禁在考前最后一夜熬夜刷题，充足的睡眠是保证第二天在第 2 小时写对 WFD 句子的唯一生理前提。

## 方案 B：14 天稳固进阶课表（最推荐的黄金备考期）

- **适用对象：** 有两周充裕备考时间，目标稳过 65 分并全力冲击 79 分（对应雅思 7.5–8.0 分）的考生。
- **阶段规划：**

| 阶段天数 | 核心聚焦模块与里程碑任务 |
|---|---|
| **第 1 天** | 全局认知（Stage 0 通读） + 全科摸底自测 + 建立错题本与发音基础 |
| **第 2–4 天** | **Tier S 核心重炮筑基期：** 每日高强度聚焦 WFD、RS、RA 三项，各分配 45 分钟；攻克阅读 FIB 核心搭配表。 |
| **第 5 天** | **第一次全真模考（Mock #1）：** 尽早暴露最短板；结合瓶颈定位表确立后续主攻方向。 |
| **第 6–8 天** | **短板定向爆破期：** 针对模考暴露出的核心瓶颈题型展开针对性强化；每日保留 60 分钟 Tier S 日常维护。 |
| **第 9–10 天** | **写作输出攻坚期：** 每日限时 1 篇完整大作文 + 2 篇 SWT + 1 篇 SST；保持 Tier S 日常维护。 |
| **第 11 天** | **第二次全真模考（Mock #2）：** 重点比对两次模考的“致错原因”变化，而非单纯看总分波动。 |
| **第 12–13 天** | **漏洞清盘与低频题防守：** 修复二模弱项；用 1 小时通读 Tier C 题型策略（RL、SGD、HIW、MCMA）。 |
| **第 14 天** | 轻松收尾。拼写大复测、草稿板默写、考场清单核对、提前休息。 |

### 第 2–13 天每日 180 分钟标准化执行切片模板

```
 10 分钟   错题本复盘（首测拼写与流程纠偏）          ← 每日雷打不动的起点
 45 分钟   听写句子 (WFD) 专项 + 拼写抄写 5 遍
 30 分钟   重复句子 (RS) 反应训练（必须录音）
 20 分钟   朗读短文 (RA) 意群划线 + 影子跟读
 30 分钟   阅读完形填空 (FIB) 逻辑搭配推导
 30 分钟   轮换模块：看图说画(DI) / 大作文 / SWT / SST / RTS
 15 分钟   将今日所有失误归纳记入错题本并标注致错原因
 ───────
共 180 分钟
```

## 方案 C：21 天从容通关课表（系统化进阶）

在 14 天课表结构的基础上，增加以下进阶调整：
1. **设置 3 次全真模考节点：** 分别在第 5 天、第 12 天、第 19 天举行。
2. **第 14–18 天逐步纳入中等难度题型攻坚：** 每天给复述讲座（RL）和讨论总结（SGD）各分配 20 分钟进行速记框架训练。
3. **第 19–20 天严格按正式考试作息模拟：** 锁定在与你正式考位完全相同的时间段（如上午 9:00 或下午 14:00）进行全封闭模拟，中途绝不停顿。
4. **第 21 天彻底放松休整。**

:::{note} 冲刺备考为何不建议超过 3 周？
超过 3 周后，这种高强度、机械化针对评分算法的技巧训练会出现明显的**边际收益递减**。如果你有更充裕的时间，推荐执行完 21 天计划后**立即去参加一次真实考试**！

PTE 通常在考后 48 小时内即出具成绩单，且转考重考极其便捷。**“早考摸清真实水平 → 针对成绩单精准修复 → 迅速二战通关”**，其备战效率远高于闭门造车数月。
:::

## 考试疲劳管理与考场生理钟适配

:::{important} 必须刻意适应的两个生理事实
1. **WFD 是整场考试的最后一项：**  
   此时你已经连续高度集中了 2 个多小时，处于大脑极度缺氧疲惫的极限状态。**在平时的练习中，务必将 WFD 安排在每次学习 session 的最后 30 分钟进行！** 在精神饱满时练出的高分，在考场末尾的疲惫状态下很容易断崖式下跌。
2. **Part 1 是长达 80 分钟的高压连贯输出：**  
   口语与写作中途没有任何休息。在考前至少必须完成一次完整连续 80 分钟的口语+写作高压模拟，提前让面部肌肉和大脑适应这种高强度耐力负荷。
:::

- **生物钟对齐：** 尽量在与正式考试完全相同的时间段进行每日核心学习。如果考试报在早晨 9:00，切勿长期在深夜 23:00 刷题。

## 极限 3 天救命抢分指南（如果仅剩 72 小时）

如果仅剩最后 3 天，请彻底放弃所有次要内容，只看以下救命模块：

| 天数 | 核心执行动作 |
|---|---|
| **第 1 天** | 研读 {doc}`../00-foundations/04-priority-triage` + {doc}`02-template-card`（45分钟）。随后：WFD 方法 + 20 句；RS 方法 + 25 句；RA 朗读 8 篇。 |
| **第 2 天** | 阅读 FIB 搭配表与解题漏斗。限时写一篇大作文，写一篇 SWT。疲劳状态下听写 WFD 15 句，跟读 RS 20 句。快速浏览 ASQ 常识题。 |
| **第 3 天** | 全力做一套完整模考；或者反复刷：WFD 15 句、RS 20 句、RA 8 篇、影子跟读。通读 {doc}`06-exam-day-checklist`。傍晚早睡。 |

> **心理预期：** 3 天的目标不是拔高英语能力，而是**彻底堵住所有低级非受迫性失误**（如作文超字数、填空留空白、口语卡壳超时、多选乱猜倒扣分）。仅把这些白送的分数保住，就能带来立竿见影的提分！

## 过程性量化指标检查清单（Checkpoints）

备考过程中，请跟踪以下**自己能够直接掌控的行为指标**，而非去纠结模考软件给出的预估总分：

| 过程量化监控指标 | 第 1 天 | 第 7 天 | 第 14 天 | 官方高分达标红线 |
|---|---|---|---|---|
| **WFD 准确率（Set B 实测）** | ___ % | ___ % | ___ % | **85%+** |
| **RS 听到哔声后开麦延迟** | ___ 秒 | ___ 秒 | ___ 秒 | **< 1.0 秒** |
| **RS 句子中间出现 >1 秒停顿次数** | ___ 次 | ___ 次 | ___ 次 | **0 次** |
| **RA 朗读中途自我纠错重启次数** | ___ 次 | ___ 次 | ___ 次 | **0 次** |
| **DI 描述图表实际用满时长** | ___ 秒 | ___ 秒 | ___ 秒 | **35–40 秒** |
| **阅读整场遗留的未作答空格数** | ___ 个 | ___ 个 | ___ 个 | **0 个（全填满）** |
| **阅读单题超时（>2分钟）次数** | ___ 次 | ___ 次 | ___ 次 | **0 次** |
| **大作文实测字数控制区间** | ___ 词 | ___ 词 | ___ 词 | **240–280 词** |
| **拼写错题本已完全攻克退役词数**| ___ 词 | ___ 词 | ___ 词 | **每周持续递增** |

:::{tip} 为什么监控这些行为指标远胜于看模拟总分？
每一个行为指标都是**你完全有能力通过纪律直接掌控的动作**，并且每一个动作都直接对应着评分引擎的分数增减。

面对“我口语模考才考了 48 分”，你往往会感到无从下手；但面对“我的开麦延迟高达 2.4 秒”，你立刻就找到了明确、具体且 3 天内就能彻底解决的纠偏靶点！
:::
