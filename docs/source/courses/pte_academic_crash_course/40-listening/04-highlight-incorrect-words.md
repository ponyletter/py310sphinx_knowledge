# 04. 标出错误词 (Highlight Incorrect Words, HIW) —— C 级倒扣分排雷指南

:::{admonition} 题型核心参数一览 (At a Glance)
:class: warning
| 核心指标 | 官方标准参数 |
|---|---|
| **考场题量** | 2–3 题 |
| **供分单项** | **听力 (Listening) + 阅读 (Reading)** 双向供分 |
| **音频输入** | 15–50 秒音频短段落，语速较快，**仅播放 1 次** |
| **交互形式** | 屏幕显示文本，鼠标点击文字即可标出该词 |
| **官方计分规则** | **点对错误词得 +1 分，误点正常词倒扣 −1 分！单题最低 0 分保底** |
| **倒扣分惩罚** | **⚠️ 有倒扣分！(YES)** |
:::

---

## 为什么将其列入 C 级？残酷的倒扣分算术账

这道题之所以让无数考生爱恨交加，原因有三：
1. **全场为数不多的 −1 倒扣分机制**：误点一个正常单词，就会把你辛辛苦苦抓到的正确词分数抵消冲销掉！
2. **要求极高强度的“眼耳同步”**：眼睛看文本的速度必须与耳朵听录音的语速保持绝对微秒级同步；
3. 音频语速飞快，且仅播放 1 次。

:::{important} C 级核心生存战术：只点 100% 确认的明显假词，宁缺毋滥！
假设一段录音中实际替换了 4 个错误词，我们来看不同点击风格的净得分：

| 你的点击策略 | 点对正确词 | 误点正常词 | 最终该题净得分 |
|---|---|---|---|
| **极度克制：只点 2 个 100% 确定的** | **2 个 (+2)** | **0 个 (0)** | **稳赚 +2 分！** |
| 激进盲猜：点了 4 个（3 对 1 错） | 3 个 (+3) | 1 个 (-1) | **仅得 +2 分！** |
| 贪心胡点：点了 6 个（4 对 2 错） | 4 个 (+4) | 2 个 (-2) | **仅得 +2 分！** |
| 碰运气狂点：点了 5 个（2 对 3 错） | 2 个 (+2) | 3 个 (-3) | **直接沦为 0 分！** |

**数学铁证**：只点 2 个绝对确定的词，拿到的净得分与“碰运气点对 4 个但误点 2 个”完全一样，而且**没有任何被清零的下行风险**！
**克制不仅是安全的，而且收益是完全对等的！**
:::

## 四步实战操作法则 (The Four-Step Method)

### 第一步：音频播放前（极速扫读，熟悉文本节奏）
音频播放前有大约 5–8 秒窗口。以极限速度扫读文本，不要试图精读，核心是**让视线和大脑提前熟悉文本的主题用词与长句节奏**，避免开考后视线冷读跟不上音频。

### 第二步：音频播放时（鼠标为笔，视线死死咬住音频）
鼠标光标放在第一个词上，眼睛随着发音的推进**逐词扫视**。当出现替换词时，你的感官会产生强烈的“违和冲击感”：眼睛看到的词和耳朵听到的声音完全对不上！

:::{tip} 考场错误词的两大经典伪装模式
替换上去的词通常在语法上完全成立，但存在语义或语音的微调：

| 屏幕上显示的词 (Transcript) | 音频中实际读出的词 (Audio) | 替换特征类型 |
|---|---|---|
| *increase* (增加) | *decrease* (减少) | **语义反差冲击 (反义词)** |
| *affect* (动词影响) | *effect* (名词效果) | 形近/音近词混淆 |
| *population* (人口) | *pollution* (污染) | 发音近似近音词 |
| *economic* (经济的) | *economical* (节俭的) | 派生形容词偷换 |
| *advantage* (优势) | *advance* (前进) | 前缀同根词 |
| *contract* (合同) | *contrast* (对比) | 音近替换 |

**实战重点抓“语义反差冲击”**：当句子突然冒出一个与上下文截然相反的反义词（如将 increase 读成 decrease），这种冲击最明显，立刻点击它！
:::

### 第三步：点击瞬间完成，视线毫不停留
一旦耳朵捕捉到不符的词，**鼠标左键点击该词，视线立刻向前移动追赶音频**！
绝不要停下来自鸣得意或犹豫反复核查，音频正在以每秒 3 个词的速度飞驰，停留 1 秒就会把下一个错误词漏掉。

### 第四步：音频结束后 —— 严禁脑补补点！(Do NOT Speculate)
:::{danger} 考后补点是导致大量考生沦为 0 分的头号杀手！
音频播放完毕后，屏幕静止下来。很多考生在这个时候喜欢重新看一遍文章，心想：“这个词看起来好像不对劲，我也点一下吧。”
**绝对严禁这种投机动作！**
只要你在听音过程中没有 100% 听出来它不同，事后凭感觉脑补点击的，多半都是正常的词！一个手抖多点一下，直接倒扣 1 分。
**音频一停，鼠标离开文本框，依靠听音中点下的 2–3 个确定词直接点击 Next！**
:::

## 初学者必须杜绝的失分误区

| 常见失分误区 | 产生后果 | 正确纠偏动作 |
|---|---|---|
| 音频播完后凭感觉补点几个可疑词 | 误点正常词倒扣负分，净得分直接被抹零 | 音频停即停手，绝不补点任何猜测项 |
| 强迫症试图把全部错误词都找出来 | 引入大量不确定的猜测，负分抵消 | 贯彻“抓到 2 个确定词就稳赚”的克制心态 |
| 视线跳跃看太快，跟丢了音频位置 | 无法比对听觉与视觉 | 鼠标箭头顺着单词滑动，严格同速跟进 |
| 专门花几周时间死磕本题 | 仅占 2–3 题且有倒扣分，性价比极低 | 把核心备考时间留给 S 级的 WFD 和 RS |
