# 03. 听力键入填空 (Listening: FIB) 极速通关指南 —— A 级听力提分题

:::{admonition} 题型核心参数一览 (At a Glance)
:class: tip
| 核心指标 | 官方标准参数 |
|---|---|
| **考场题量** | 2–3 题 |
| **供分单项** | **听力 (Listening)** |
| **音频输入** | 30–60 秒学术短录音，**仅播放 1 次** |
| **文本呈现** | 屏幕展示录音的听力原文抄本，其中挖去 3–5 个空格 |
| **官方计分规则** | **每拼对一个单词得 1 分**，最低 0 分 |
| **倒扣分惩罚** | **零倒扣分！(NONE)** 拼错或乱写不扣分 |
:::

---

## 练好 WFD 即可免费附赠高分的题型！

题目流程极其直观：屏幕上印着一段英文录音的文字抄本，但抠掉了几个单词。录音播放一遍，你通过键盘把挖掉的单词**手动打字填入空格中**。

**这与压轴大题 Write from Dictation (WFD) 考查的核心能力完全一致** —— 听音辨词、短期留存、准确拼写。但它比 WFD 甚至更容易：因为**上下文所有其他单词全部白纸黑字印在屏幕上**！你在听到那个词之前，就已经可以推导出它需要什么词性和语法成分。

:::{important} 训练复用启示：无需单独设立漫长的复习周期
不要为 L-FIB 专门规划几周的独立训练。**只要你在 {doc}`01-write-from-dictation` 中把听写意群和学术高频词拼写练扎实，本题的能力已经自动完成了 85% 以上**！你只需要做几道真题熟悉界面打字节奏即可。
:::

---

## 现场实战五步破题法 (The Five-Step Method)

### 第一步：音频播放前（极速扫读，语法预判）
音频播放前有约 5–7 秒的倒计时。**立刻扫视各空格的前后紧邻单词**，预判缺失词的词性：

> "Researchers have found that urban trees ________ air quality by trapping ________ particles, although the effect ________ considerably between species."

无需听到任何声音，仅凭语法推导：
- 第 1 空：必须是**谓语动词原形**（如 *improve / affect*）；
- 第 2 空：修饰名词 particles，必须是**形容词**（如 *harmful / microscopic*）；
- 第 3 空：主语是 the effect（单数），必须是**第三人称单数动词加 -s**（如 *varies / differs*）！

预判之后，当录音播放时，你的耳朵是在针对性捕捉已知词性的词，听力辨音难度瞬间减半！

### 第二步：音频播放时（双手放键盘，眼耳同步敲击）
:::{note} 与 WFD 截然相反的作答战术
WFD 录音只有 3 秒，必须听完再在纸上速记；
而 L-FIB 录音长达 30–60 秒，屏幕上有完整文本。**双手直接搭在键盘上，视线紧随音频播放，听到一个词立刻实时在空格里打出来！** 视线永远保持比音频播放快 2–3 个词，提前为下一个空格做好准备。
:::

### 第三步：万一漏听，绝不停顿！
如果某一个空没听清，**绝对不要停在原地发愣思考！**
音频绝不会等你。如果你卡壳 2 秒，紧接着随后的两个空都会全部错过！
**没听清立刻放过它，视线迅速紧跟音频走向下一个空格！** 音频播完后你依然可以自由点击之前的空格输入补救。

### 第四步：音频结束后（依据语法逻辑全填满，绝不留白）
**本题零倒扣分！** 面对任何漏听的空格：
1. 利用第一步推导出的词性；
2. 结合全篇学术主题（如讨论植物光合作用，填入一个相关的学术词）；
3. **哪怕是纯蒙，也必须把每一个空格全部敲满单词！**

### 第五步：终极拼写与单复数 -s 核验
官方标准是：“每拼对一个单词得 1 分”。拼错字母直接判 0 分。
核对两处最隐蔽的雷区：
- **主谓单复数与 -s 结尾**：看屏幕上打印的主语是单数还是复数；
- **过去式 -ed 结尾**：结合上下文时态核实。

## 空格中高频挖掉的四大学术词类

PTE 官方从不在空格中挖 *a, the, in, at* 这种无意义的虚词，挖空的 95% 以上都是承载核心信息的学术实词：

| 词类属性 | 考场经典空格真题词汇 |
|---|---|
| **核心学术专业名词** | *photosynthesis, urbanisation, sediment, biodiversity, inflation* |
| **高频学术动词** | *demonstrate, indicate, contribute, fluctuate, correlate, accelerate* |
| **程度副词与数据量化词** | *significantly, considerably, approximately, substantially, dramatically* |
| **评价与属性形容词** | *crucial, inherent, widespread, negligible, feasible* |

这些词汇全部收录在本书的 {doc}`../60-toolkit/01-core-vocabulary` 中。
