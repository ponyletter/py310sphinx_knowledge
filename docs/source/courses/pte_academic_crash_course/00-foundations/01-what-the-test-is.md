# 01. 什么是 PTE 学术考试？底层机制、核心优势与考场全流程 (What the Test Is)

## 极速概览 (The Short Description)

PTE 学术英语考试（PTE Academic）是一门**完全基于计算机交付、全流程由 AI 人工智能算法评分**的学术英语语言测试。考生在 Pearson 官方考点单次完成考试，全程佩戴专业降噪耳麦、对着麦克风发音、在键盘上键入文本并使用鼠标答题。**全程无考官面试，无纸笔作答**。考试成绩通常在 **48 小时内**发布（多数考生在 24 小时甚至考完当天即可查到）。

根据培生官方《PTE Academic Test Taker Score Guide》（2025年版）：

> "PTE Academic 是针对学术背景下个人英语语言能力的计算机化评估。考试总时长最多为 2 小时 15 分钟，通过真实语料来源的试题，全面考查考生的听、说、读、写四大交际技能（Communicative Skills）。"

:::{note} 官方时长与实际考场体验
培生 2025 年官方机构版评分指南标注为约 2 小时 18 分钟，考生版标注为 2 小时 15 分钟。官方改版公告显示，多数考生实际完成时间**在 2 小时以内**。考生规划备考体力时以 2 小时 15 分钟为基准即可，细微差异不影响备考节奏。
:::

## 为什么说 PTE 是国内考生更容易快速提分的选择？ (Why PTE is Often the Easier Choice)

明确这个底层逻辑，能帮助你把宝贵的精力精准投放至能够快速变现的分数洼地上：

| 核心特性 (Feature) | 对考生的实战意义与战略影响 (Consequence for you) |
|---|---|
| **全程无真人考官介入** | 彻底告别面对考官的心理紧张与人际压迫感；杜绝了真人考官的地域口音偏见。机器只检测声学信号特征与算法指标，不吃“临场魅力”或“努力讨好”。 |
| **对着机器标准化输出** | 你可以使用高度公式化、机械平稳的语音节奏。在真人面试中显得生硬的“播音腔/平稳语调”，在机器评分引擎中反而是**流利度（Oral Fluency）满分**的最佳利器。 |
| **交叉赋分机制 (Integrated Scoring)** | 一道题目往往同时给两门技能供分（例如：听写一句话同时给听力和写作贡献巨额分值）。抓住交叉赋分核心题，就是极速提分的捷径。 |
| **出分极快、考位极频** | 考完当天或次日即可查分。如果不幸偶有失手，可以快速预约下一场进行微调。很多考生将首次实战当作快速查漏补缺的体检。 |
| **绝大部分题型设有步骤分 (Partial Credit)** | 只要抓住关键点或部分词汇即可拿分。在没有倒扣分规则的题目中，**坚决不要留白**，写出残存记忆词汇也能拿走实质性分数。 |

## 考试三大模块与顺序流程 (The Three Parts, In Fixed Order)

PTE 严格遵循固定的模块流程。**一旦离开当前部分，绝无法返回上一部分**；在阅读与听力的大多数题型中，一旦点击 `Next` 进入下一题，便无法返回上一题修改。

```
┌─────────────────────────────────────────────────────────────────┐
│  第一部分：口语与写作 (PART 1 — SPEAKING & WRITING)  约 76–84 分钟│
│  ─────────────────────────────────────────────────────────────  │
│  Personal Introduction 自我介绍 (不计分，1题，热身开嗓)            │
│  Read Aloud 朗读文本 (RA)                   6–7 题              │
│  Repeat Sentence 复读句子 (RS)             10–12 题             │
│  Describe Image 描述图像 (DI)               5–6 题              │
│  Retell Lecture 复述讲座 (RL)               2–3 题              │
│  Answer Short Question 简答题 (ASQ)         5–6 题              │
│  Summarize Group Discussion 小组讨论总结 (SGD) 2–3 题 [2025新题]  │
│  Respond to a Situation 情境回应 (RTS)      2–3 题 [2025新题]   │
│  Summarize Written Text 概括文本 (SWT)      2 题 (每题独立10分钟)│
│  Write Essay 大作文 (WE)                    1 题 (独立20分钟)   │
└─────────────────────────────────────────────────────────────────┘
                               ↓  中途无任何休息，直接衔接
┌─────────────────────────────────────────────────────────────────┐
│  第二部分：阅读 (PART 2 — READING)                 约 23–30 分钟│
│  ─────────────────────────────────────────────────────────────  │
│  Fill in the Blanks (Dropdown) 下拉完形填空 (RW-FIB) 5–6 题     │
│  Multiple Choice, Multiple Answers 多选题 (R-MCMA) 2–3 题 (负分) │
│  Reorder Paragraph 段落排序 (RO)            2–3 题              │
│  Fill in the Blanks (Drag & Drop) 拖拽填空 (R-FIB)   4–5 题     │
│  Multiple Choice, Single Answer 单选题 (R-MCSA)    2–3 题       │
│  ── 阅读部分为全模块总倒计时，考生必须自主严格配速分配时间 ──   │
└─────────────────────────────────────────────────────────────────┘
                               ↓  考完阅读后，提供可选的 10 分钟中场休息
┌─────────────────────────────────────────────────────────────────┐
│  第三部分：听力 (PART 3 — LISTENING)               约 31–39 分钟│
│  ─────────────────────────────────────────────────────────────  │
│  Summarize Spoken Text 听力总结 (SST)       1 题 (独立10分钟)   │
│  Multiple Choice, Multiple Answers 听力多选 2–3 题 (有负分)     │
│  Fill in the Blanks (Type In) 听力填空 (L-FIB) 2–3 题           │
│  Highlight Correct Summary 匹配总结 (HCS)   2–3 题              │
│  Multiple Choice, Single Answer 听力单选    2–3 题              │
│  Select Missing Word 补全遗漏词 (SMW)       1–2 题              │
│  Highlight Incorrect Words 选出错误词 (HIW) 2–3 题 (有负分)     │
│  Write from Dictation 听写句子 (WFD)        3–4 题 [全场压轴绝杀]│
└─────────────────────────────────────────────────────────────────┘
```

:::{tip} 新手必须牢记的两大考场结构事实
1. **Write from Dictation (WFD) 是整场考试的收尾压轴大题**：经过前两个小时高度专注的体力和脑力消耗，你将在最疲倦的状态下迎来整场考试分值最高、提分最快的题目。平时训练听写句子时，请务必模拟疲惫状态下的抗干扰默写。
2. **第一部分口语加写作是长达约 80 分钟的高压连轴转**：口语紧接写作，中间没有任何喘息机会。在正式考前，请至少完成一次完整 80 分钟连续不中断的口语写作模考，培养耐力。
:::

## 什么是“交叉赋分 / 综合技能”？—— PTE 战略规划的灵魂

培生官方评分指南明确定义：

> "部分题目同时考查两项交际技能，被称为综合技能题（Integrated Skills Tasks）。这些任务的得分将**同时计入**被评估的两个交际技能分数中。"

这意味着你在成绩单上看到的“听、说、读、写”四大单项分数，并不是由四个相互独立的模块单独结算出来的，而是由分布在整场考试中的各题型协同供分：

| 你的 **口语 (Speaking)** 分数来源 | 题量 |
|---|---|
| Read Aloud (朗读文本, RA) | 6–7 题 |
| Repeat Sentence (复读句子, RS) | 10–12 题 |
| Describe Image (描述图像, DI) | 5–6 题 |
| Retell Lecture (复述讲座, RL) | 2–3 题 |
| Summarize Group Discussion (小组讨论总结, SGD) | 2–3 题 |
| Respond to a Situation (情境回应, RTS) | 2–3 题 |
| **口语供分总量** | **约 28–34 题（全部集中在 Part 1）** |

| 你的 **写作 (Writing)** 分数来源 | 题量 |
|---|---|
| Summarize Written Text (概括文本, SWT) | 2 题 |
| Write Essay (大作文, WE) | 1 题 |
| Summarize Spoken Text (听力总结, SST) | 1 题 |
| Write from Dictation (听写句子, WFD) | 3–4 题 |
| **写作供分总量** | **仅约 7–8 题！** |

| 你的 **阅读 (Reading)** 分数来源 | 题量 |
|---|---|
| 阅读五大自有题型 (RW-FIB, R-FIB, RO, MCMA, MCSA) | 15–20 题 |
| Summarize Written Text (概括文本, SWT) | 2 题 |
| Highlight Correct Summary (匹配听力总结, HCS) | 2–3 题 |
| Highlight Incorrect Words (选出错误词, HIW) | 2–3 题 |
| **阅读供分总量** | **约 21–28 题** |

| 你的 **听力 (Listening)** 分数来源 | 题量 |
|---|---|
| Repeat Sentence (口语中的复读句子, RS) | 10–12 题 |
| Retell Lecture (口语中的复述讲座, RL) | 2–3 题 |
| Answer Short Question (口语中的简答题, ASQ) | 5–6 题 |
| Summarize Group Discussion (口语中的讨论总结, SGD) | 2–3 题 |
| 听力八大自有题型 (SST, L-FIB, HIW, WFD 等) | 15–22 题 |
| **听力供分总量** | **约 35–45 题（口语贡献占据近半壁江山！）** |

:::{admonition} 备考全书最具战略价值的核心结论
:class: important
**写作总分仅由 7–8 道题决定，其中多达 3–4 题是听力部分的 Write from Dictation (WFD)！**

WFD 评分极其机械化：按正确拼写的单词逐词计分，拼对一个给一分，**写错或多写词不倒扣分**。它同时决定了你写作和听力两项大分。对于基础薄弱、急需短期达标的考生，**突击拿下 Write from Dictation 是全场投资回报率（用时对提分产出比）最高的战略行动**。详细打法参见：{doc}`../40-listening/01-write-from-dictation`。
:::

## 考试当天现场流程与物理细节 (Exam-Day Process)

以下整理自培生官方考生手册与标准化考场规则（具体以你的考点最终确认信为准）：

1. **至少提前 30 分钟到达考点**：迟到将直接被拒绝入场并没收考试费。
2. **身份证件核查**：中国大陆考点通常必须提供**有效护照原件**（港澳居民可按当地考点要求出示有效回乡证或护照）。**任何复印件、扫描件、电子证件均视为无效**。证件上的姓名拼音、出生日期与性别必须与报名账户完全一致。
3. **生物识别采集**：考务人员进行身份复核、**掌静脉特征扫描（Palm-vein scan）**、现场面部采集拍照及电子签名确认。
4. **随身物品强制寄存**：手表、手环、首饰、纸巾、硬币、钱包、手机等一切个人物品存入考场储物柜，口袋必须全部掏空。
5. **考位文具发放**：考务人员提供专用的**可擦写塑料草稿册（Erasable Noteboard）与专用细头记号笔**。考生严禁携带任何自带纸笔，草稿册写满可举手示意考务人员更换。
6. **耳机与麦克风试音环节（最关键动作）**：考试开考前系统提供耳机音量调节和录音回放检查。**请务必严格按照规范佩戴麦克风**——麦克风位置偏差将直接毁掉整场口语成绩！
7. **Personal Introduction 自我介绍**：25 秒阅读准备，30 秒录音，仅有一次录音机会。该部分**完全不计入任何分数**，仅用于递交申请机构时的声音留存；请将其作为正式开考前的嗓音预热和喷麦检查。
8. **正式答题**：完成阅读部分后，系统会弹出**可选的 10 分钟中场休息**选项，建议举手离开考位去洗手间、活动肩膀并深呼吸。
9. **出分与发送成绩**：官方通常在 48 小时内将分数推送至你的 MyPTE 账号，可免费无限次将电子成绩单直递给全球目标院校和移民局。

:::{warning} 试音绝不是走过场的形式主义
口语中的 Pronunciation（发音）和 Oral Fluency（流利度）覆盖约 30 道题，由 AI 算法对你的声学波形特征进行特征提取。麦克风距离嘴唇过远，波形微弱、信噪比低，算法无法识读辅音爆破；距离过近，呼吸气流会造成严重爆音（Pop）和波形削顶失真。

**正确位置：距离嘴角约一拳（或两横指），斜置于下唇侧下方，避开鼻息和嘴部呼气直吹气流。** 说话音量保持为“坐在会议桌对面与人对话”的适中洪亮音量。试听录音时，如果声音发闷、有风暴杂音或过于细微，**在考试正式开始前立刻举手让考务人员更换耳麦或调整设备**！
:::

## 新手最容易掉入的四大致命扣分陷阱 (The Four Costliest Beginner Mistakes)

1. **麦克风静音超过 3 秒直接关闭**：在任何口语题中，如果系统检测到超过 3 秒没有有效声音输入，麦克风将自动切断并直接跳题，该题彻底作废。**听到提示音后 1 秒内必须立即开口**，哪怕发音不完美，也绝不要沉默。
2. **死记硬背大段空洞模板**：2025 年新版机评体系已全面强化 Content（内容度）门槛。大段空洞通用的万能套话会被直接识别为“Irrelevant response”，导致 **Content=0**。而 Content 为 0 会触发连锁反应，连带导致流利度与发音分数全部归零！详见：{doc}`03-how-scoring-works`。
3. **阅读部分时间管理失控**：阅读部分是全模块共用单一倒计时（约 25 分钟，完成 15–20 题）。大量初学者在前面的段落排序（RO）题上死磕 8 分钟，导致后面分值极高、极易捡分的阅读填空（FIB）连看都没看就交卷了。详见：{doc}`../30-reading/04-section-tactics`。
4. **字数与格式违规导致整题清零 (Form 判 0)**：大作文低于 120 词、文本概括（SWT）不是单一单句、听力概括（SST）低于 40 词，将直接在 Form 维度被判 0 分，白白损失基础分。各题型格式雷区详见：{doc}`02-item-inventory`。
