# 05. 核心术语词典与“机经题库”真相揭秘 (Glossary and Banks)

## 第一部分：机经预测、真题题库与官方试题真相 (Part A)

在各大社交媒体和备考群里，充斥着各种“机经”、“真题”、“绝密预测题库”的宣传。很多新手由于分不清概念，白白浪费了大量金钱和宝贵复习时间。本章为你彻底揭开底层真相。

### 市面上常见概念到底是什么？

| 常见概念名称 | 它的本质到底是什么？ | 真实度与参考价值 |
|---|---|---|
| **官方底层题库 (Item Pool)** | 培生官方后台真实、庞大、受最高安全等级保护的私有题库。每次考试由系统根据算法自动动态抽题组合。**官方从未对外公开，永不出版发布。** | 真实存在，但外部绝对无法接触到原题库。 |
| **预测机经 (Prediction Files)** | 国内外培训机构根据全球历次考生在考后凭记忆**口述回忆 (Recollections)** 汇编而成的回忆录合集，通常按周或月更新。 | **极具刷题实战价值**。但机构宣传的“命中率 80%”多为商业包装，缺少第三方独立核验。 |
| **高频机经 / 重复题 (High-Frequency Items)** | 在大量考生的回忆中频繁出现重叠的一批经典题目。因为官方题库体量有限，特定题型确实会周期性循环复用。 | **真实有效**。高频母题库是提速复习的极佳语料。 |
| **“官方历年真题” (Past Papers)** | **在 PTE 考试中根本不存在历年真题！** 培生不像雅思或高考那样公开退役往年整卷。任何声称出售“官方原版真题试卷”的均属于虚假宣传。 | ❌ 概念不成立，本质均属于考生回忆版机经。 |
| **官方计分模拟考 (Official Scored Practice Tests)** | 培生官方在 `pearsonpte.com` 付费发售的官方在线模拟考（A/B/C/D/E 卷）。 | **唯一跑官方真实评分引擎的模考系统**，极具考前诊断价值。 |

### 为什么 PTE 考试中真的会反复出现原题？

题库虽然庞大，但绝非无限。更核心的技术机理在于：**PTE 的 IRT（项目反应理论）评分模型要求每道题目必须具备已校准的统计难度参数**。为了维持评分尺度的长期一致性，官方必须在全考场环境中重复投放已校准的题目。因此，“真题反复出现”是计算机自适应自校准测试的固有技术特征，而不是所谓的“题目泄露”。

### 如何科学利用机经预测题？—— 核心问答法则

:::{admonition} 决定如何使用机经的唯一终极法则
:class: important
**自问：这项任务是在奖励“原词原句记忆复刻”，还是死记硬背会直接导致“Content 判 0 分”？**
:::

根据上述法则，各题型对待机经的态度截然不同：

| 题型分类 | 死记机经是否有用？ | 为什么？实战操作准则 |
|---|---|---|
| **听写句子 (WFD)** | ✅ **极度有用！回报极高** | 该题考核的就是逐词精确还原。如果你在平时刷题时已经把该句的单词拼写和结构背得滚瓜烂熟，考场上听到前半句就能瞬间闭眼默写！这是刷机经最正当、最高效的阵地。 |
| **复读句子 (RS)** | ✅ **非常有价值** | 考核的是语音回声复述。提前听过高频音频，考场上听到时短时记忆压力骤降 80%。 |
| **简答题 (ASQ)** | ✅ **直接见效** | 固定的一词常识答案（例如问：“企鹅属于鸟类还是哺乳类？”）。提前刷一遍高频词表就是直接白捡听力分。 |
| **阅读/听力完形填空 (FIB)、段落排序 (RO)** | ✅ 有效，但需防范陷阱 | 考前刷到过能帮助你秒懂上下文。**但绝对不要死背选项顺序！** 官方可能会微调挖空位置。必须通过题目去理解词汇搭配与句意逻辑。 |
| **描述图像 (DI)、复述讲座 (RL)、情境回应 (RTS)、讨论总结 (SGD)** | ⚠️ **仅用于熟悉图表与题材，严禁背诵死模板！** | 提前看图表有助于预判生词。**但千万不要死记硬背成篇现成答案**！大段背诵现成答案直接触发 Content=0，并连带导致全题发音流利度清零。必须掌握句式脚手架现场提取信息。 |
| **大作文 (WE)、文本概括 (SWT)、听力概括 (SST)** | ⚠️ **仅用于话题拓展与词汇储备** | 提前了解常考学术母题（人工智能、环保、城市化、公共教育）有助于拓宽观点。考场上严禁死背整篇范文硬套，必须紧扣题干实词现场论述。 |

### 备考资源防坑省钱建议

1. **不需要花大价钱购买天价题库**：市面上的公开开源平台、备考网站以及本指南提供的练习题库已足以覆盖 95% 以上的高频题。
2. **唯一值得付费的官方模考**：如果预算允许，考前一周在培生官网购买 1 套官方 Scored Practice Test 进行实战全仿真演练。因为任何第三方平台的评分算法都只是近似模拟，唯有官方模考跑的是培生内部同一套评分算法。
3. **仔细核验资料的时间线**：**凡是 2025 年 8 月改版前出版的攻略书籍或机经合集，全面淘汰！** 旧资料缺少 SGD 和 RTS 两种全新口语题型，且给分走向（如宣称 RA 算阅读分、完形填空倒扣分等）全面失真。

:::{warning} 法律边界与备考红线
- 考生根据记忆回忆整理、用于课后练习的机经属于全球通行的合规备考方法。
- **严禁**携带任何违规设备试图在考场偷录、窃取考场试题，一经发现将面临全球禁考与取消过往全部成绩的严厉处罚。
- **考场内坚决用自己的嘴巴表达提炼出的有效信息**，切勿生搬硬套死背的所谓“万能范文”。
:::

## 第二部分：官方核心术语与备考圈黑话词典 (Part B)

### 培生官方术语体系 (Pearson Official Terms)

- **交际技能 (Communicative Skills)**：成绩单上正式呈现的听、说、读、写四大语言单项分数（10–90 分）。
- **综合技能题 (Integrated Skills Items)**：跨模块同时考查并给两个单项同时赋分的题目（如 RS 同时给听力和口语供分）。全套高效提分策略的基石。
- **特质维度 (Traits)**：系统对单题从细分维度进行的量化评价指标（包括内容度 Content、口语流利度 Oral Fluency、发音 Pronunciation、格式 Form、语法 Grammar、词汇 Vocabulary、拼写 Spelling 等）。
- **内容度 (Content)**：考生的回答是否实质性触及了题干要求。口语模块的核心前置闸门——若 Content 为 0，后续流利度与发音直接判 0 分！
- **格式合规 (Form)**：针对特定字数和形式的硬性要求（如大作文 120–380 词、SWT 必须为 5–75 词的单一复合句）。
- **口语流利度 (Oral Fluency)**：语流的连贯平滑度、意群停顿与节奏感。
- **项目反应理论 (IRT, Item Response Theory)**：PTE 评分背后的高阶心理测量学模型，依据试题难度和考生反应向量动态计算总分，使总分不同于算术平均分。
- **智能作文评估器 (IEA, Intelligent Essay Assessor™)**：用于批改写作主观题的自动化系统，运行于知识分析技术 (KAT™) 之上，核心算法为潜在语义分析 (LSA)。
- **Versant 语音引擎**：培生自主研发的语音特征处理系统，跨越全球百余种母语口音，精准分析声学波形以评判流利度与发音。
- **全球英语水平测试标准 (GSE, Global Scale of English)**：培生制定的 10–90 分粒度的全球英语能力标尺。
- **欧洲语言共同参考框架 (CEFR)**：国际通行的 A1–C2 语言等级体系。
- **SELT 与 UKVI**：英国签证与移民局认可的安全英语语言测试。PTE Academic UKVI 的考试内容、题型与评分标准与普通 PTE Academic 完全一致，唯一区别是成绩单上附带一个用于英国签证系统核验的 SELT URN 编码。

### 备考社区高频“黑话”与惯用语

- **炸 (Target Scores)**：备考圈对目标达标的形象称呼：
  - **六炸 (50+)**：相当于雅思 6.0，满足绝大部分预科与常规本科准入。
  - **七炸 (65+)**：相当于雅思 7.0，海外名校研究生常规录取线。
  - **八炸 (79+)**：相当于雅思 8.0，澳洲/新西兰技术移民最高档语言加分（20 分）必备。
- **官方模考 (Mock / Scored Mock)**：在培生官网进行的带官方 AI 评分的模拟测试。
- **句式脚手架 (Sentence Frames)**：区别于空洞万能模板的合规结构，仅保留逻辑连词与骨架，内部核心词汇全部现场提取自题干。
- **流利度压倒一切 (Fluency over Accuracy)**：PTE 口语的核心铁律。在流利度和个别单词纠错之间，永远牺牲纠错、捍卫语流连贯平稳。
- **意群切分 (Chunking)**：将长句按语法意义切分成 3–5 个词的意群块进行短时记忆与连读输出。
- **影子跟读 (Shadowing)**：录音播放延迟半秒后同步模仿原声音调、重音和节奏的跟读训练法。
- **倒扣分 (Negative Marking)**：仅在阅读多选、听力多选以及标出错误词 (HIW) 中生效的扣分机制。
- **可擦写草稿板 (Noteboard)**：考场提供的塑封格子草稿册与专用可擦水笔，听写与记笔记的唯一纸面工具。
- **PTE Core 与 PTE Home (注意避坑)**：
  - **PTE Academic**：本课程全篇专攻的学术英语考试（适用于留学申请、澳洲/新西兰移民及英国签证）。
  - **PTE Core**：专门针对加拿大经济类移民的通用英语考试（题型与 Academic 有很大差异）。
  - **PTE Home**：仅考听力和口语的英国定居/家庭类签证测试。
  - **开考前请务必与你的院校或移民顾问核实，确认报考的是 PTE Academic！**
