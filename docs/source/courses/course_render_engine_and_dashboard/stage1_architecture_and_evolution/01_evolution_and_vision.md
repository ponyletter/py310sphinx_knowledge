# 1.1 自动化短视频生产全景与演进复盘

## 一、传统知识短视频制作的痛点与瓶颈

在传统的知识分享、技术科普与教育内容制作中，一个 2~3 分钟的高质量横屏/竖屏视频通常需要经历以下繁重的工序：

1. **文案撰写与试读**：撰写讲稿，反复删改字数以适配口播节奏；
2. **手绘/分镜素材制作**：利用 Illustrator、Photoshop 或平板绘制黑板手绘图，一张复杂架构图往往需要数小时；
3. **录音与剪辑降噪**：讲师录制干音，处理喷麦、口水音与语速不均；
4. **视频轴线粗剪与对齐**：在剪映或 Premiere 中逐句导入音频，手工切割分镜并对齐画面关键帧；
5. **字幕切分与拍轴**：自动转录工具经常在“专有名词”、“长数字”或“固定成语”处断句，需要人工反复校对；
6. **封面与发布文案**：单独设计各平台尺寸封面，提取标签、撰写文案与首评引导。

对于需要高频输出的创作者而言，**这种依靠人工拼接的流程在规模化（Batch Production）时几乎不可持续**。

## 二、新范式：“图片主导（Image-Led）”与代码化渲染

本项目采用的核心范式是：**“视频的本质是由高密度生成图片构成的画卷”**。

```{mermaid}
flowchart LR
    A["自然语言需求<br/>(One-line Topic)"] --> B["大模型智能策划<br/>(剧本/分镜/生图Prompt)"]
    B --> C["高质感位图插图<br/>(AI生成无文字留白黑板图)"]
    B --> D["连贯克隆声音<br/>(IndexTTS 2.5 驱动)"]
    C & D --> E["强制对齐引擎<br/>(Faster-Whisper / CTC)"]
    E --> F["代码化合成流水线<br/>(HyperFrames + FFmpeg)"]
    F --> G["最终交付成果物<br/>(1080P MP4 + 3:4 封面 + 文案)"]
```

### 核心设计原则：
1. **画面完全由位图表达**：杜绝使用枯燥的网页 DOM 框线、SVG 粗劣图表或空白黑板。如果场景需要展示网络调用链路、数据库锁机制或历史事件，必须将整个黑板图谱、带箭头的流程和中文标注**一体化生成在图片内部**；
2. **分镜与解说句强绑定**：每一张插图都关联一个精确的 `reveal_sentence`（揭示句子序号），声音念到该句时画面自适应推入焦点；
3. **统一讲师音色与卡通形象**：全课使用相同的克隆声学参考，封面与结尾统一绑定创作者的专属 Q 版人像，建立强烈的 IP 辨识度。

## 三、系统架构核心三元组

为了实现生产、调度与沉淀的高效分工，整个产品生态由三个解耦的工程项目协同组成：

| 项目组件 | 仓库定位 | 核心职责 |
| :--- | :--- | :--- |
| **`course-render`** | 核心渲染内核 (Codex Skill) | 课件剧本策划、场景插图生成、连贯语音合成、字幕强制对齐、独立封面渲染、视频合成门禁校验 |
| **`course-render-dashboard`** | 调度与中台控制 (FastAPI WebUI) | 移动端/桌面端任务提交、多任务并发控制（FCFS队列）、安全目录防重分配、用户专属形象与音色画像、Cloudflare R2 自动同步 |
| **`py310sphinx_knowledge`** | 知识沉淀与文档平台 (Sphinx) | 将短视频剧本与案例深度沉淀为长篇图文、代码架构与操作手册，支撑长期搜索引擎索引与多端消费 |

## 四、架构演进脉络复盘

在系统的演进过程中，架构经历了三次重大跃迁：

### 阶段一：单体脚本与本地 CLI 探索
* **特征**：依赖本地开发者在终端依次手动执行 `generate_voice.py`、`align.py` 和 `render.py`。
* **缺陷**：操作繁琐，缺乏并发互斥保护，当两个任务同时跑 TTS 时，容易造成显存耗尽崩溃；封面尺寸固定且无法灵活换脸。

### 阶段二：工业级技能内核与规范确立（PR #51 跃迁）
* **演进**：
  1. **独立封面引擎规范 (`cover_spec.json`)**：将封面从固定 HTML 截图中解耦，支持 3:4 竖版封面单独配置，引入文字安全区、静止区域重试算法与 Q 版人像边缘光晕分离；
  2. **跨进程显卡安全互斥 (`gpu_lock.py`)**：在机器级别通过跨进程文件锁对 IndexTTS 配音与 CTC 语音对齐实施序列化排队，保证高并发下零显存冲突；
  3. **多分类体系扩展**：从纯技术科普（tech）扩展至国学文化、创业商业、产品运营、情感关系与亲子教育等多套分镜与讲述模版；
  4. **原创度与防碰撞校验**：引入 `check_originality.py` 和文字遮挡计算，未达标的课件禁止进入最终渲染。

### 阶段三：面向多用户的无头调度与云边缘交付（Dashboard v2）
* **演进**：
  1. **解耦无头驱动**：控制台不侵入内核代码，通过标准 `codex exec -C <project> --json` 外部拉起智能体作业；
  2. **云边协同分发**：无缝对接 Cloudflare R2 对象存储，移动端直接生成免登录高速下载链接；
  3. **网络穿透与安全反代**：结合 FRP 隧道与 Nginx 自动化 SSL 证书，将私有算力机安全暴露为公网可访问的 HTTPS 生产端点。
