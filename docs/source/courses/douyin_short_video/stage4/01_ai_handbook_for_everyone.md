# 必学课程：人人能懂的AI小白书

面向非技术创作者的人工智能通识与实战提效全景手册，帮助创作者跨越技术门槛，享受智能时代的生产力红利。

---

## 第 1 章 AI 基础认知与工具全景

### 1.1 生成式人工智能（AIGC）的底层逻辑
* **大语言模型 (LLM)**：不是有自主意识的“神”，而是基于海量人类文本预训练的**高维概率接龙机器**。输入越清晰、上下文越明确，输出的精准度越高。
* **多模态演进 (Multimodal)**：从早期的纯文本对话，到目前图像生成、语音克隆、高清视频生成的跨模态协同。

### 1.2 创作者主流 AI 工具梯队
* **文本与脚本生成**：ChatGPT / Claude / Kimi / DeepSeek / 通义千问。
* **图像与封面设计**：Midjourney / Stable Diffusion / 即梦 (Dreamina)。
* **语音合成与克隆**：Fish Speech / GPT-SoVITS / CosyVoice。
* **视频生成与扩展**：Runway Gen-3 / Kling 快手可灵 / Sora。

## 第 2 章 创作者日常工作流与提效实战

### 2.1 提示工程（Prompt Engineering）四步实战法
要获得惊艳的脚本，杜绝模糊提问（如“帮我写个短视频脚本”），遵循结构化提示词公式：
```text
【角色设定】：你是一位全网拥有 200 万粉丝的硬核科技与知识科普短视频总编导。
【任务目标】：请针对主题《为什么电脑重启能解决 90% 的故障》，编写一条 60 秒的短视频口播脚本。
【叙事风格】：通俗风趣，必须包含一个生活化通俗比喻（如把内存比作办公桌面），严禁使用书面说教词汇。
【结构要求】：
  - 0~3 秒：反常识黄金悬念开场
  - 4~20 秒：通俗比喻拆解底层原理
  - 21~45 秒：演示 1 个绝大多数人都不知道的快捷键排查技巧
  - 46~60 秒：金句总结，并引导评论区互动
```

### 2.2 全自动内容提效生产工作流
1. **热点抓取**：利用脚本每天定时监控行业热点与竞品高赞评论。
2. **AI 头脑风暴**：批量生成 10 个具有认知差的差异化选题角度。
3. **分镜自动拆解**：自动生成景别（特写/全景）、台词、配套音效与画面提示词。
4. **人工润色交付**：注入个人独特经历与情感灵魂，完成批量高效生产。
