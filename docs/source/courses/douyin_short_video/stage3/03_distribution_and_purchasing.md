# 必学课程：分销采购实战篇：老黄讲运营

系统掌握短视频供应链对接、精选联盟选品、分销代发与后端履约闭环，打通商业变现实操路径。

---

## 第 1 章 供应链与选品逻辑

### 1.1 精选联盟与分销模式解析
* **轻资产代发（一件代发）**：博主仅需专注前端内容创作与小黄车促单，由供应链源头商家直接发货并处理售后，佣金自动由平台划转。
* **高转化选品三大黄金指标**：
  * **评分标准**：店铺体验分 $\ge 4.8$ 分，退款率低于行业均值。
  * **佣金率合理性**：一般保持在 $15\% \sim 35\%$ 之间，过高的佣金往往意味着商品虚标或品控堪忧。
  * **内容契合度**：商品必须深度融入视频场景（如：讲编程附带机械键盘/颈椎按摩仪，讲收纳附带收纳神器）。

## 第 2 章 流量承接与销售转化

### 2.1 视频带货的黄金说服结构
1. **痛点放大**：展示生活中繁琐、痛苦的真实场景。
2. **神器亮相**：拿出产品，直观展示 3 秒解决问题的过程。
3. **资质/材质背书**：特写展示做工、安全认证或国家标准检测报告。
4. **价格锚点与催单**：“在商场买要上百元，今天在小黄车点击进入只要一杯奶茶钱”。
