## 2. 微信官方：快速接入虚拟支付（个人与商户）

针对广大独立创作者，微信官方提供了专门的虚拟支付接入指南：
- **官方权威文档链接**：[微信公众平台 · 个人主体虚拟支付接入指引](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment/person.html)

### 2.1 个人主体虚拟支付接入核心要点
针对没有注册公司的个人开发者，微信官方开放了合规的个人虚拟支付通道：
1. **开通门槛**：个人小程序必须完成实名认证与工信部 ICP 备案，且账号信用分达标；
2. **结算模式**：支持小额数字内容、道具直购与研学鼓励模式，由腾讯官方代收代付并定期清算至个人实名绑定的银行账户；
3. **接口调用流程**：
   - 客户端调用 `wx.requestVirtualPayment` API 唤起微信官方收银台；
   - 传入由服务端计算的 `signData`（签名包）、`paySig`、`signature` 等防篡改参数；
   - 微信服务器完成支付后，通过 Webhook 回调通知后端服务器，服务端执行发货并写入购买流水记录。

### 2.2 虚拟支付提审合规核验清单
在对接官方虚拟支付能力并提审时，务必对照以下清单逐一核验：
- [x] 是否已正确配置发货通知与用户订单中心（订单中心 Path 指向正确）；
- [x] iOS 客户端是否遵守平台规范，无现金违规诱导充值；
- [x] 是否已在显著位置展示《用户服务协议》与虚拟数字化商品性质提示；
- [x] 提审前沙箱环境 `XPAY_ENV` 是否已平滑切换为现网正式生产环境 `0`。
