## 2. 沉淀：Antigravity 提审自动化审查 Skill 设计

为了让本次宝贵的排错与合规经验能够永久赋能未来的新项目，我们将其固化为 Antigravity 技能规范（Skill Specification）：

### 2.1 Skill 核心审查流水线（Pipeline）
```text
wechat-miniapp-audit Skill:
├── [Check 1: 敏感交易词汇扫描] : 自动 grep 检测全端代码中是否存在 "¥"、"购买专栏"、"立即充值"
├── [Check 2: WXML 语法栈校验] : 运行 Python AST 验证脚本，确保每个 <view>、<text> 严格平衡闭合
├── [Check 3: SWC 编译器免疫检查] : 扫描 JS 代码中是否误用 ES6 数组扩展解构 [...arr]
├── [Check 4: 兜底防御与空值检测] : 检查 <image> 是否配置 binderror，检查默认头像是否为空字符串
└── [Check 5: 审核通道与开关核查] : 检查后端 .env 是否配置 ENABLE_AUDIT_LOGIN 开关，检查凭证是否手动输入
```

### 2.2 Skill 规则清单与自检命令
在未来任何小程序提审前，只需在智能助手输入提示词：
> *"请运行 wechat-miniapp-audit 自检脚本，对本项目的前端与后端进行上线前合规与语法扫描。"*

助手即可根据预置规则，自动完成上述 5 大维度的深度体检并出具体检报告，将审核驳回率直接降为 0！
