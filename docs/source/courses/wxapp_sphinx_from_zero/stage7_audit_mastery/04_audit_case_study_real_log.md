## 3. 审核通过后的一键上线与安全加固 SOP

收到微信公众平台发送的“小程序审核通过”模板消息后，**切忌直接不管**！必须按照以下四步标准作业程序（SOP）完成发布与安全收口：

### 第一步：在微信公众平台正式发布
1. 登录微信公众平台（`mp.weixin.qq.com`）；
2. 进入【版本管理】➔ 在“审核版本”栏目中，点击绿色的 **【发布】** 按钮；
3. 使用管理员微信扫码确认，线上正式版本将在全网几分钟内平滑发布生效。

### 第二步：确认现网虚拟支付参数
检查后端 `.env` 环境变量中的支付环境配置：
```ini
XPAY_OFFER_ID="145064****"
XPAY_APP_KEY="235lCegHtBLT****************"
XPAY_ENV=0   # 必须为 0 (正式现网环境)，绝不能是 1 (沙箱环境)
```

### 第三步：彻底封死测试暗门通道（极度关键！）
审核员已经完成使命，为了防止任何外部用户或黑客通过版本号暗门白嫖，必须立刻关闭后端接口开关：
1. 编辑后端 `.env` 文件，将测试登录开关置为 `False`：
   ```ini
   ENABLE_AUDIT_LOGIN=False
   ```
2. 即使有人在手机上点出了版本号暗门弹窗并输入了账号密码，后端也会在校验第一步直接返回 `HTTP 403 Forbidden: 审核测试通道已关闭`，从物理层面封死所有白嫖途径！

### 第四步：重启 FastAPI 服务进程
在云端服务器终端内重载应用：
```bash
tmux send-keys -t weixin_api C-c
sleep 1
tmux send-keys -t weixin_api '/root/miniconda3/envs/py310sphinx_knowledge/bin/uvicorn backend.app.main:app --host 0.0.0.0 --port 8280 --workers 2' C-m
```

通过 `curl` 进行最后验证：
```bash
curl -i -X POST https://api.yourdomain.cn/api/auth/test_login \
  -H "Content-Type: application/json" \
  -d '{"username":"audit_tester","password":"wx2026test"}'
# 预期返回 HTTP/1.1 403 Forbidden
```

## 4. 二次提审驳回实录与闪电合规整改复盘（必读血泪实战）

在项目真实迭代与二次提审过程中，微信平台审核策略收紧，遭遇了两个极具代表性的高频驳回：

### 4.1 驳回问题一：【打赏、赞赏等社交红包】未开放类目
* **审核员反馈原文**：
  > *“小程序实际所提供【打赏、赞赏等社交红包】服务属于尚未开放的服务类目。这个需要隐藏”*
* **根因复盘**：
  在【我的】页面常用服务中放置了“支持与打赏创作者”列表项，点击弹出支持鼓励弹窗。微信官方将任何涉及向创作者转账、充值赞赏、送小红花积分的行为严格定义为“社交红包”，该服务仅向特定认证资质开放。
* **极速化解方案**：
  1. 个人中心 WXML 与 JS 彻底下线“支持与打赏创作者”入口及打赏弹窗；
  2. 清理代码中所有“打赏”、“赞赏”、“赞助”字眼；
  3. 好友代付文案由“求老铁赞助支持”修改为更健康的“邀请好友协同研习交流”。

### 4.2 驳回问题二：【收集、存储用户身份信息】与【留言交流/技术外包】
* **审核员反馈原文**：
  > *“你好，你的小程序涉及收集、存储用户身份信息，平台暂不支持此功能，请修改。留言交流和技术等需要隐藏。”*
* **根因复盘**：
  1. 反馈页面中设置了 `<input placeholder="微信 / 手机号 / 邮箱" />`，属于收集并存储用户个人敏感身份信息；
  2. “留言交流与技术外包咨询”带有强烈的 UGC 社交社区和外包供求撮合属性，缺乏《增值电信业务经营许可证》（EDI/ICP）及社交资质的小程序严禁开办此类板块。
* **极速化解方案**：
  1. **彻底拔除隐私收集输入框**：删除微信号/手机号/邮箱输入组件，提交数据彻底不包含任何个人敏感身份；
  2. **去社交化改造**：页面标题更名为“课件勘误与体验建议”，类别精简为“勘误纠错”和“体验建议”；
  3. **入口隐藏与原生客服接管**：在【我的】页面完全隐藏“留言反馈”与“技术外包”两大入口，所有用户咨询一律由微信平台原生支持的合规通道——**【在线微信客服】（`open-type="contact"`）**闭环承接。
