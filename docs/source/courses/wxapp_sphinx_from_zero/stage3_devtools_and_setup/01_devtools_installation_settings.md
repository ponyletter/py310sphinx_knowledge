# 微信开发者工具保姆级安装与核心详情配置

对于从传统 Web 或后端转过来的开发者，微信开发者工具（WeChat DevTools）不仅是一个编辑器，更是一个高度封装的**模拟运行时环境**。本章详细讲解工具的下载安装、项目导入与核心编译选项的配置奥秘。

---

## 1. 下载、安装与扫码登录

1. **官方正版下载**：访问微信开放文档（`developers.weixin.qq.com`），进入【工具】➔【开发者工具下载】，根据操作系统选择 **“稳定版 (Stable Build)”**（Windows 64位或 macOS Apple Silicon/Intel 版）；
2. **扫码授权**：安装完成后启动，使用已绑定该小程序开发者或管理员权限的个人微信扫码登录。

---

## 2. 正确导入小程序工程（常见第一坑）

在工具欢迎界面点击【导入】（Import）：

```text
项目导入目录规范：
/root/02project/weixinpy310sphinx_knowledge/
├── backend/          (Python 服务端，不要选这个！)
├── miniapp/          <--- 必须选中此目录！(包含 app.json, app.js, project.config.json)
└── sphinx_docs/      (文档源码，不要选这个！)
```

- **项目名称**：例如 `创作工坊知识库`；
- **目录**：必须选中包含 `app.json` 的 **`miniapp`** 目录；若选到整个仓库根目录，工具会提示“未找到 app.json”而无法识别；
- **AppID**：填入上一阶段在微信公众平台获取的真实 AppID（如 `wxef6c0e98e63627a8`），也可暂时选用“测试号”，但测试号无法调试虚拟支付等受保护接口。

---

## 3. 核心“详情（Project Settings）”配置深度拆解

在开发者工具右上角点击 **【详情】(Details)**，切换到 **【本地设置】(Local Settings)**，这里的每个复选框都对编译行为有着决定性影响：

```{mermaid}
graph TD
    Settings[开发者工具 - 详情 - 本地设置]
    Settings --> Opt1[不校验合法域名、web-view、TLS版本以及HTTPS证书]
    Settings --> Opt2[将 JS 代码编译成 ES5]
    Settings --> Opt3[增强编译]
    Settings --> Opt4[上传代码时自动压缩样式/脚本]
```

### 3.1 核心配置项解析与生产避坑对照表

| 配置开关 | 作用原理 | 推荐开发阶段设置 | 提审与上线前注意事项 |
| :--- | :--- | :--- | :--- |
| **不校验合法域名、web-view、TLS版本以及HTTPS证书** | 允许在工具模拟器中向任意 HTTP 接口或内网 IP（如 `http://127.0.0.1:8280`）发起网络请求，绕过域名白名单检测。 | **勾选开启**（方便本地快速联调接口） | **注意**：真机调试和正式上线时此配置无效！线上环境 100% 严格校验白名单，必须配置合规的 HTTPS 域名。 |
| **将 JS 代码编译成 ES5** | 将现代 ES6/ES7 语法（如 `async/await`、箭头函数、模板字符串）转译为兼容低版本微信内核的原生 ES5。 | **勾选开启** | 微信当前底层引入了 Rust 编写的 SWC 编译器，特定语法解构可能会触发依赖缺失报错（我们在第 6 阶段将重点讲解排雷）。 |
| **增强编译** | 开启微信官方底层优化的 Babel/TypeScript 支持，提供更强健的 Polyfill 与模块化支持。 | **推荐开启** | 能大幅减少未知 JS 引擎差异带来的语法崩溃。 |
| **上传代码时自动压缩** | 自动对 WXML、WXSS、JS 进行混淆和空格剔除，大幅缩小安装包体积。 | **必须开启** | 微信规定小程序**主包体积不得超过 2MB**，开启压缩是避免包体积超标的关键手段。 |

## 4. project.config.json 工程配置文件同步

开发者工具中的所有“详情”配置，最终都会持久化在项目根目录下的 `project.config.json` 文件中：

```json
{
  "miniprogramRoot": "./",
  "projectname": "创作工坊知识库",
  "description": "项目配置文件",
  "appid": "wxef6c0e98e63627a8",
  "setting": {
    "urlCheck": false,
    "es6": true,
    "enhance": true,
    "postcss": true,
    "minified": true
  },
  "compileType": "miniprogram"
}
```

将该文件纳入 Git 版本控制，能够确保团队内任何新成员拉取代码后，开发配置保持 100% 严格一致。
