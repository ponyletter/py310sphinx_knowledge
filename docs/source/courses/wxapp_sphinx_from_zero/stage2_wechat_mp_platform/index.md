# 第2阶段 微信公众平台保姆级全流程操作

微信公众平台是小程序开发者的“控制中枢”。从账号类型选择、类目审批，到全网推行的工信部小程序 ICP 备案，再到 AppID 凭证获取、合法域名配置与虚拟支付申请，每一步都是 0 基础小白极易卡壳的“深水区”。本阶段将手把手带你扫清全部平台级障碍。
