# 虚拟支付（米大师/XPay）与用户隐私保护指引配置

如果你的小程序涉及任何**“数字化虚拟商品”**（如电子书、专栏阅读权限、积分点数、会员特权），微信官方有着极其严苛的专门通道和准入规则。普通微信支付（JSAPI 现金支付）会被直接判定为违规。本章详细拆解**微信虚拟支付 2.0（XPay）**的接入全流程与**用户隐私保护指引**的合规设置。

---

## 1. 为什么数字内容不能走普通微信支付？

微信生态对商品类别有着泾渭分明的划分：

```{mermaid}
graph TD
    Goods[用户发起付款] --> Physical{商品形态}
    Physical -->|实物电商/生活服务| PayA[普通微信支付 JSAPI / 微信商户平台]
    Physical -->|数字内容/专栏/积分/会员| PayB[微信虚拟支付 2.0 XPay / 米大师平台]
    PayA --> CheckA[走快递物流与订单履约，免收苹果抽成]
    PayB --> CheckB[微信官方托管代币体系，统一合规清算]
```

### 1.1 违规后果与平台红线
如果在数字内容（技术文档专栏）中直接调用传统的微信商户 JSAPI 支付唤起微信收银台，在提交版本审核时会遭到**100% 秒拒**，驳回理由通常为：
> *“小程序涉及虚拟支付，iOS 端不可提供任何购买、支付、充值行为，安卓端必须接入微信虚拟支付能力。”*

---

## 2. 微信虚拟支付 2.0（XPay）接入实战

微信推出了全新一代虚拟支付系统（**XPay / 微信小游戏与小程序虚拟支付**），由微信官方直接向开发者结算。

### 2.1 开通申请流程
1. 登录微信公众平台 ➔ 左侧进入【功能】➔【虚拟支付】；
2. 签署《微信小程序虚拟支付服务协议》；
3. 提交结算银行账户信息（企业或个体工商户对公/法人对私银行卡）；
4. 获得核心商户参数：
   - **Offer ID（业务标识）**：例如 `1450640476`；
   - **沙箱 AppKey（测试专用）**；
   - **现网 AppKey（生产上线专用）**：例如 `235lCegHtBLT2UwGqimaRWQ7UpLtaENe`。

### 2.2 沙箱环境 vs 现网环境切换法则（极度关键！）

| 环境类型 | `env` 参数 | 适用场景与特性 |
| :--- | :--- | :--- |
| **沙箱测试环境** | `XPAY_ENV=1` | 用于本地开发联调。开发者可以使用虚拟测试货币进行扣款，**不会产生真实银行资金扣款**。此环境仅限开发者微信白名单可用。 |
| **现网正式环境** | `XPAY_ENV=0` | **提交平台审核以及发布上线时必须切换为此模式！** 使用真实资金结算，全部微信用户可用。如果在提审时仍保留沙箱环境，审核员验收支付接口时会因非白名单账号报错而判定“功能不可用”予以驳回。 |

## 3. 《用户隐私保护指引》配置标准规范

自 2023 年 9 月 15 日起，微信对用户个人信息的保护进入最严监管期。未配置或配置不合规的小程序，所有涉及敏感接口（获取头像、写入剪贴板、定位等）将直接静默失效。

### 3.1 必须声明的核心隐私信息项及合规填报模板

进入公众平台【设置】➔【基本设置】➔【服务内容声明】➔【用户隐私保护指引】：

| 收集的个人信息类型 | 接口或行为 | 官方推荐合规使用目的填报模版（即抄即用） |
| :--- | :--- | :--- |
| **用户信息（微信昵称、头像）** | `chooseAvatar`、`type="nickname"` | *“用于在个人中心展示个性化学习档案与专栏会员身份标识，方便用户识别自己的研学进度与资产信息。”* |
| **剪贴板信息** | `wx.setClipboardData`、`wx.getClipboardData` | *“用于快捷复制用户专属 UID、邀请口令、兑换码以及技术支持微信号，提升用户交互便利性。”* |
| **网络信息与存储** | `wx.request`、`wx.setStorage` | *“用于持久化存储用户登录凭证 Token、文章离线阅读缓存以及阅读进度定位。”* |

### 3.2 开发者承诺与注销路径声明
在隐私指引下方，必须勾选并明确填写：
1. **信息保存期限**：选择“在提供服务期间持续保存，用户注销账号后立即删除”；
2. **用户投诉与注销渠道**：填写官方客服微信号或在小程序内提供【意见反馈与留言】通道。
