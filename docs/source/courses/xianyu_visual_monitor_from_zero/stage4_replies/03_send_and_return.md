# 12 中文粘贴、图片 Open 与 F5 返回

## 文字发送的不可删减步骤

目标行唯一 → 点击后标题相符 → 最新气泡来自客户且等于触发文本 → 输入框为空 → 中文剪贴板粘贴 → 发送前重新读完整草稿、目标和最新输入 → 回车 → 核实发出气泡及失败图标。

气泡存在只是证据之一；发送失败的红色感叹号可能晚于气泡出现，所以保留验证窗口。程序核实也不能替代首次上线时接收端的收讫确认。

## 图片选择曾遇到的真实问题

GTK 文件选择器中按回车曾触发取消，关闭窗口却没有真正选择文件。修复后读取对话框标题、完整路径和 Open 按钮，且只点击一次 Open。光标还会干扰路径 OCR，路径输入完成后先移走焦点再读。

## 为什么必须返回列表

保持选中客户会话可能让后续来信自动已读。完成或安全取消后，应先保存观察到的新上下文，再按 F5，确认列表锚点健康、聊天区域没有选中客户。发送结果和返回结果分别记录。

不得点击“闲小蜜／闲鱼助手／系统通知／官方通知”等系统会话代替退出，点击可能跳转其他页面。草稿、未知目标或未核实对话框阻止自动 F5，以免丢内容或在错误窗口输入。

已知问题 #21：只用旧图坐标变化判断“新图”可能被滚动欺骗；#22：空闲返回尚无人工阅读停留时间。课程快照中它们仍未修复，不能把正常路径验收当作这些问题已经消失。

**交付**：文字、图片、返回列表三项独立结果，以及“用户收到几张图”的确认。
