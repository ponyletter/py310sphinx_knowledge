# 23 迁移到其他网页和桌面软件

最值得复用的是事件、任务、核验、暂停、审计和恢复机制，而不是原闲鱼坐标。其他应用若有经过授权的官方接口，应优先评估接口适配；必须视觉操作时，再实现独立屏幕适配器。

## 可复用边界

```python
# 设计接口示意，不是当前代码里已经存在的类
class ScreenAdapter:
    def observe(self, frame): ...       # 结构化证据，不直接发送
    def verify_target(self, frame, target): ...
    def locate_composer(self, frame): ...
    def verify_receipt(self, frame, intent): ...
    def return_to_idle(self): ...
```

每个应用定义自己的系统会话、气泡颜色、标题特征、弹窗、发送按钮与失败标志。新适配不能沿用“右边气泡必为我发”这一未经验证的假设：有些界面布局、语言方向和消息类型不同。

|迁移对象|可能复用|必须重做|
|---|---|---|
|自有 Web 客服后台|规则／任务箱／管理 UI|页面适配、身份 ID 与权限|
|桌面聊天客户端|OCR 和输入基础设施|窗口焦点、系统弹窗、附件及回执|
|ERP／工单软件|审计与不可逆动作状态机|业务字段、保存与提交确认|
|远程运维面板|健康与批量配置|认证模型和命令权限|

## 判断是改现有系统还是另建适配器

如果仍然是“消息观测 → 客户回复”，可在现有核心上抽象平台适配层；如果动作变成订单结算、文件删除或其他事务，应重建业务状态机，仅复用基础设施。不要将一个万能点击器包装成跨行业成品。

**练习**：选择一个自己控制的软件，录制合成或授权画面，定义 10 个正常状态和 5 个异常状态，先完成离线观测测试再允许任何输入。
