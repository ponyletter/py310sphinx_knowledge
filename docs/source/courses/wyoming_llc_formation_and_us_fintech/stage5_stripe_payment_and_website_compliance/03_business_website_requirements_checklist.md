# 5.3 Stripe 审核必过的合规商业网站要素核验清单

> **核心导语：**
> 在申请 Stripe 时，您必须提供一个代表您业务的网站 URL。Stripe 出于反欺诈和合规性要求，会对该网站进行严格的审查（无论是自动化扫描还是人工复核）。本节将提供一份“必过清单”，教您如何快速搭建一个符合合规要求的网站，避免申请被拒。

---

## 为什么 Stripe 要求活跃网站？

金融机构必须遵守严格的 KYC（了解你的客户）和 AML（反洗钱）法规。Stripe 需要通过您的网站确认：
1. 您销售的产品或服务是真实、合法的。
2. 您没有从事受限或禁止的业务（如成人内容、伪劣商品、部分金融衍生品等）。
3. 您的业务对消费者是透明的，具备清晰的退款和隐私条款。

```{admonition} 绝对红线
:class: danger
**您的网站必须在提交 Stripe 申请前就已经上线并可供公开访问！**
带有密码保护、处于 "Coming Soon"（敬请期待）状态、或者只有空白模板的网站，将被 Stripe 100% 拒绝。
```

## 强制性网站要素检查清单

为了确保一次性通过审核，您的网站必须包含以下要素。请对照此表进行检查：

| 网站要素 | 是否必需 | 详细说明 |
| :--- | :--- | :--- |
| **产品/服务描述** | ✅ 必需 | 清晰准确地说明您在卖什么、用户将获得什么。绝不能含糊其辞。 |
| **定价页面 (Pricing)** | ✅ 必需 | 价格必须公开透明。如果是订阅制，需列明不同层级 (Tiers) 及其包含的功能。 |
| **退款政策 (Refund Policy)** | ✅ 必需 | 明确说明在何种条件下可以退款，以及如何取消订阅。 |
| **隐私政策 (Privacy Policy)** | ✅ 必需 | 说明您如何收集、使用和保护用户数据，以符合 GDPR/CCPA 等法规。 |
| **服务条款 (Terms of Service)** | ✅ 必需 | 规定用户使用您产品时的法律条款和责任限制。 |
| **联系方式** | ✅ 必需 | 至少提供客服邮箱 (Support Email)。最好加上公司名称和您的 Wyoming 注册地址。 |
| **HTTPS 证书** | ✅ 必需 | 网站必须使用 SSL/TLS 加密（即网址以 `https://` 开头）。这是支付合规的基础。 |
| **独立域名** | ✅ 必需 | 必须使用您自己的域名（如 `yourbusiness.com`）。严禁使用免费的子域名（如 `.github.io`, `.vercel.app`）。 |
| **'Coming Soon' 页面** | ❌ 拒绝 | 页面必须包含真实的业务内容，不能是“建设中”状态。 |

## 快速建站方案推荐

作为开发者，您不需要花几周时间去开发一个庞大的官网。为了通过审核，一个单页面应用 (SPA) 或简单的静态页面即可。以下是一些低成本且高效的方案：

1. **Carrd**（极力推荐）：每年仅需 \$19，提供极其精美的落地页模板，支持绑定自定义域名，非常适合 SaaS 预售或 MVP 展示。
2. **Next.js / Astro + Vercel**：对于前端开发者，使用这些框架构建静态站并免费部署到 Vercel（别忘了绑定你购买的顶级域名）。
3. **Hugo / Jekyll + GitHub Pages**：极客之选，纯 Markdown 写作，免费托管（需绑定自定义域名）。
4. **Framer**：强大的无代码工具，适合设计驱动型产品。

## Stripe 审核机制与常见被拒原因

### 审核机制
- **自动扫描**：Stripe 爬虫会自动抓取您的网站，识别关键词，检查 HTTPS 和联系方式。
- **人工复核触发器**：如果您的行业被标记为“中高风险”，或者您的描述包含敏感词汇，系统会将您的申请转交人工团队审核。

### 常见被拒原因及修复方法
1. **未提供退款政策**：这是最常见的错误。
   - *修复*：在页脚 (Footer) 添加指向专门的退款政策页面的链接，哪怕你的政策是“数字产品概不退款”。
2. **描述不清**：审核员看不懂你是做什么的。
   - *修复*：使用最简单的语言说明：“We provide a SaaS tool that helps users schedule tweets.”
3. **行业属于高风险/禁止类**：
   - *修复*：仔细核对 Stripe 的 [Restricted Businesses](https://stripe.com/legal/restricted-businesses) 列表。确保您的文案没有产生不必要的歧义。
