# 阶段三：EIN 联邦税号申请（无 SSN 路径）

本阶段攻克非美国居民申请联邦雇主识别号（EIN）的核心难关。由于没有 SSN/ITIN，无法使用 IRS 在线申请系统，必须通过 Form SS-4 传真或第三方代办渠道完成。

从 SS-4 表格全 18 行逐字段填写指南，到 DIY 传真与 Fiverr 代办两条路径的成本-时间权衡，再到 CP 575 首发确认函与 147C 验证信的区别与获取方式，本阶段确保你以最短时间拿到银行和 Stripe 开户的前置核心凭证。
