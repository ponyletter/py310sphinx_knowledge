# 阶段一：美国 LLC 全景认知与怀俄明州选型决策

本阶段为整个课程的认知基石。在动手注册公司之前，必须首先理解 LLC（有限责任公司）的法律本质、税务穿透机制、不同州之间的核心差异，以及 Wyoming 独有的"充押保护令（Charging Order）"资产保护优势。

只有建立了正确的底层认知框架，才能在后续的注册、开户、收款与合规全链路中做出最优决策，避免因误选实体类型（如错选 C-Corp）或错选注册州（如选了年费 \$300 的 Delaware）而付出数千美元的沉没成本。
