# 2.1 前置筹备清单：材料准备、查重规则与通信选型

> **核心导语：** 注册美国 LLC 是一项严肃的法律行为，充足的准备能极大提高注册通过率并避免后续踩坑。在开始动手前，请务必备齐以下所有材料与环境。

---

## 材料准备清单

| 类别 | 必需材料 | 详细要求与说明 |
| :--- | :--- | :--- |
| **身份证明** | **有效的中国护照** | 必须是护照！**绝对不能用中国身份证**，因为后续开户（Stripe、Mercury）绝大多数不认可非英文字符的身份证。 |
| **公司名称** | 拟定的 LLC 名称 | 必须以 `LLC`, `L.L.C.`, 或 `Limited Liability Company` 结尾。<br>需在 [Wyoming WyoBiz](https://wyobiz.wyo.gov/Business/FilingSearch.aspx) 提前查询是否重名。 |
| **数字资产** | 匹配的国际域名 | 建议前往 GoDaddy / Namecheap 确认与公司名匹配的 `.com` 或 `.io` 域名是否可注册。 |
| **地址信息** | 真实的中国住址 | 用于 KYC（KYB）审查。请准备好英文拼音版地址（按美式从小到大顺序排列）。 |
| **业务描述** | 简短的英文商业描述 | 说明公司主要业务，例如：`Software Consulting`，`Cross-Border E-Commerce` 或 `SaaS Subscription`。 |
| **联系方式** | **合规的美国手机号** | 用于银行收发验证码。**千万不要用 Google Voice/Skype 等 VoIP 号码**（会被银行直接拒签）。见下文推荐。 |
| **资金证明** | 银行存款证明 | （非注册 LLC 必需，但开户 Mercury 必需）建议准备招商银行的中英文版存款证明单。 |

## 合规的美国实体手机号解决方案

数字银行（特别是 Mercury 和 Relay）的合规审查非常严格。他们能够通过电信数据库识别你的手机号是实体号码（Wireless）还是虚拟号码（VoIP）。**使用 VoIP 号码是导致开户被拒的头号原因。**

我们推荐以下两种可在国内使用的实体号方案：

### 方案一：Ultra Mobile PayGo (性价比与稳定性之王)
- **费用**：\$3 / 月
- **网络**：真正的 T-Mobile 实体网络（Wireless 级别）
- **特点**：包含 100 分钟通话，100 条短信，国内可开启 Wi-Fi Calling，完美接收所有银行验证码。
- **获取方式**：淘宝或京东搜索“Ultra Mobile 3刀”，大约 200 RMB 左右买断实体 SIM 卡，插卡即可激活。

### 方案二：Tello eSIM (速度最快，即时可用)
- **费用**：最低 \$5 / 月（自选套餐，无需流量）
- **网络**：T-Mobile 网络，支持 eSIM
- **特点**：如果你有支持 eSIM 的手机（非国行 iPhone 等），可以直接在线支付购买并扫码激活，无需等待邮寄。
- **获取方式**：官网 Tello.com 注册即可。

```{admonition} 护照扫描踩坑警告 (来自 xuantongai 的实战教训)
在后续申请某些金融服务（如 ITIN 或部分支付网关）时，系统可能会要求上传身份证明。

```
