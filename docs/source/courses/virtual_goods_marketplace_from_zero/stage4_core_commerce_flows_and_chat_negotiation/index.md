# 阶段四：核心业务闭环：闲鱼式即时聊天、议价与履约交付

> **深入实现闲鱼风格的“聊中改价”、HMAC 防篡改数字签名报价卡片、购物车多商品合并结算、定制服务买家凭据收集与工单化售后流转闭环。**

---

## 阶段导读

虚拟商品电商的转化率生命线，在于**沟通是否无缝、议价是否可信、交付是否直观**。

传统的“加客服好友手工转账”模式，买家缺乏安全感，客服也容易记错金额；而纯货架式发卡又冷冰冰无法砍价。24goods 将**闲鱼的聊天砍价互动体验**与**严密的密码学签名和状态机**深度融合：
- 客服与买家在聊天窗中直接沟通；
- 客服一键发送专属报价卡片；
- 买家点击即可直接调用收银台付款，付款后卡密或工单自动挂钩会话流流转，打造无缝转化的高净值闭环。
