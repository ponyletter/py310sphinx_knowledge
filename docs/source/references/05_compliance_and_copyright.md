# 合规边界与知识版权指南

知识科普博主第一资产是信任度与合规安全性，远离虚假信息与侵权风险。

---

## 1. 政策法规与广告边界

* **《中华人民共和国广告法》与《互联网广告管理办法》**
  * 严禁极限用词（“第一”、“国家级”、“最佳”等）。
  * 医疗、药品、保健食品、金融投资类视频的特殊准入资质与话术禁区。
* **[国家市场监督管理总局](https://www.samr.gov.cn/)**
  * 虚假宣传案例通报与互联网执法合规指南。

---

## 2. 事实核查与学术背书源头

* **[科学辟谣平台](https://piyao.kepuchina.cn/)**（中国科协 / 中央网信办）
  * 权威科学辟谣智库，规避伪科普与民间误区。
* **[CNKI 中国知网](https://www.cnki.net/) / [Google Scholar](https://scholar.google.com/)**
  * 查阅一手论文实验数据与实证结论，为短视频文案提供可靠论据支持。
* **[国家知识产权局](https://www.cnipa.gov.cn/) / 中国版权保护中心**
  * 商用字体、商用音效与影视素材合理使用（Fair Use）的法律边界。
