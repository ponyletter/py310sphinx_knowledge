# 推荐系统与算法工程原理

不把算法当黑箱玄学，从正统工业级推荐系统的技术演进与核心环节理解内容分发。

---

## 1. 工业级顶级技术团队博客

* **[字节跳动技术团队博客 (ByteDance Tech)](https://blog.byteintl.com/)**
  * 字节官方工程师分享的大规模推荐架构、实时流式计算、图神经网络与多目标优化实践。
* **[美团技术团队博客](https://tech.meituan.com/)**
  * 国内推荐系统领域公开技术干货质量最高的团队之一。
  * 重点查阅：*《深度学习在美团推荐系统中的探索与实践》*、*《推荐系统召回与重排机制》*。
* **[快手技术团队公开资料](https://kuaishou.github.io/)**
  * 短视频短内容场景下的滑动长序列推荐模型与冷启动算法探索。

## 2. 学术顶会与论文检索

* **ACM RecSys (ACM Conference on Recommender Systems)**
  * 全球推荐系统领域最高学术会议，关注最新冷启动、多任务学习与多样性优化。
* **KDD / SIGIR / WWW**
  * 工业界大规模数据挖掘与检索推荐前沿论文。
* **[arXiv.org](https://arxiv.org/)**
  * 搜索关键词：`ByteDance Recommendation`, `Multi-Task Ranking`, `Exploration and Exploitation (EE)`, `Debiasing in Recommender Systems`。
