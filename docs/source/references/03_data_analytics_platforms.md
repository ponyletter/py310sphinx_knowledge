# 数据看板与行业大盘智库

以数据驱动内容选题、爆款复盘和账号诊断，告别主观臆测。

---

## 1. 短视频大数据分析平台

* **[蝉妈妈 (Chanmama)](https://www.chanmama.com/)**
  * 头部达人榜单、热点视频实时监控、带货转化数据、粉丝画像结构分析。
* **[飞瓜数据 (Feigua)](https://www.feigua.cn/)**
  * 深度短视频数据监控，支持分秒级完播与留存漏斗逆向分析。
* **[新榜 (NewRank)](https://www.newrank.cn/)**
  * 全网内容生态洞察、新媒体发展指数月报、垂直赛道涨粉榜单。

---

## 2. 宏观趋势与消费洞察平台

* **[巨量算数 (Ocean Engine Data)](https://trendinsight.oceanengine.com/)**
  * 字节官方大盘数据洞察平台，支持查看关键词搜索热度指数、内容相关联想词、行业年度趋势白皮书。
* **[艾瑞咨询 (iResearch)](https://www.iresearch.com.cn/)**
  * 互联网受众行为变迁、知识服务行业研究报告。
